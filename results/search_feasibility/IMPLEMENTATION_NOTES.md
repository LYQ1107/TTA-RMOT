# 计算前固定的实现口径（不改 PREREG）

原文预注册先公开于 `db2207c5003a5fe03c15d9799def8908bccdc56a`。以下只消除数据表示和统计实现歧义，不新增解码器、阈值或判定。

1. 列表主键为 JSON 数组 `[target, video, frame, query]`。列表子种子为该主键与根种子 0 的 SHA256 前四字节（大端无符号整数）；每次使用 `numpy.random.RandomState(subseed).permutation(N)[:m]`。同一列表跨模型、校验者共享子种子。
2. `C_online` 计数单位是“后到的回答”：若与任何一个先前回答矛盾，计一次，除以实际提问数；同时保存提问顺序与回答以供复核。不是把所有矛盾配对数除以提问数。
3. DENSE 保留实际 Yes 集合，不强制改成前缀；其表中 `b_hat` 表示实际输出数量。NATIVE 同样用输出数量。其余搜索方法的 `b_hat` 就是前缀分界。
4. F1/precision/recall 对固定的一对一匹配候选集合计算；数量误差和存在性对完整 GT 数 g 计算。无候选匹配但 g>0 时空输出 F1=0；只有 g=0 且空输出 F1=1。零分母 precision/recall 报 0，并明确 F1 的上述特例。
5. H2-a 按每个目标中两个跨域排序来源的全部有定义 `(列表, 排序来源)` 汇总平均冲突；不把同域参照混入。H2-b 分别对三种教师计算，不混用不同教师的门槛。
6. 总关卡逐教师检查：同一种教师必须同时满足 Dance 两个跨域 H1、H2-a 和 H2-b，才构成完整可行证据。全部教师的分项与联合判定都报告，不把不同教师各自的优势拼成一个成功系统。
7. bootstrap 按完整视频聚类，2000 次、seed 0；汇总点估计仍是原文的逐列表均值，不改成等视频权重。每次重采样携带一个视频的全部句子、帧、排序来源和方法。KITTI-V2 不做 bootstrap。未定义的 AUROC/相关性明确留空，不补 0 或 0.5。
8. GT-free 输入准备和搜索两个独立进程均安装打开审计；搜索仅获纯 runtime 列表读权限及自己的输出写权限。GT 标注、ORACLE 搜索和离线指标在搜索封存后运行，不将任何结果回写搜索输入。新 GPU/教师/模型调用与训练次数均为 0。
