# 计算前固定的口径与用户澄清

原文预注册先公开于 `b98041f31860de5296f452e9c156e529c131c45c`。本文件不替换原文、不新增判定或方法。

1. 用户明确答复：`nτ≥3` 对 FRAME、SEGMENT、TRACK 统一过滤；片段按帧号每 L 帧切分，不按实际观测数量切分。每条轨迹以首观测帧 t0 为起点，窗口 `[t0+kL, t0+(k+1)L)`；空窗口不补观测。末窗口到轨迹末帧的含端点时间跨度若 `<L/2`，并入前一非空窗口；没有前段时保留唯一片段。KITTI/Dance/Sports 分别固定 L=20/40/50。
2. 先按 v2 在完整每帧候选库上做 score-independent IoU≥0.5 一对一匹配，再对所有粒度统一取合格轨迹的观测；不因过滤重新分配匹配，不插值、不改框/ID/帧号。轨迹和片段标签的 50% 分母均是该单元实际观测数，不是时间跨度。
3. 用户明确答复：Sports 敏感性保留 v4 GT 内容，仅限制为原官方418条序列，重算 T1/T2/T3 及对应 AUROC、前缀和二分指标。原文第1节的“第5节判定”指向歧义已据此澄清，不使用8条缺行旧模板、不把 Sports 没有空表达当作可做存在性 AUROC。
4. MEAN/MEDIAN 按通常算术定义；TOP25 取 `max(1, ceil(n/4))` 个最高 margin 的均值；LOGIT_MEAN 按原定义计算，用 log-sigmoid/logsumexp 的等价稳定形式，不裁剪或修改原 margin。排序并列沿用前轮：分数降序、数值 track_id 升序；前缀上限多个 k 同分取最小 k。
5. AUROC 同时保存各粒度所有有定义单元的原始均值与未定义数。T1 公平主比较只用 FRAME 至少一帧有双类、SEGMENT 有双类、TRACK 有双类的共同 q；FRAME 先在 q 内对有定义帧平均，再在共同 q 之间平均。四种 TRACK 聚合同一批 q；同域与跨域也共用同一标签/候选/q 集合。没有双类的 q 不填默认 AUROC。
6. FRAME 前缀上限先逐帧计算（包括同质标签帧），再在 q 内平均；与 TRACK 比较时两个粒度都对同一批有候选 q 平均。T2 用全部合格 q 的 TRACK 上限（按原文，无正例时 k=0、F1=1），另拆出官方 GT-present/empty 和 Y-positive/zero 组，避免空集占优掩盖前缀损失。对象数分布按物理帧/视频各计一次，不把同视频重复表达当新候选。
7. 噪声率用 decompose 全部原始 CROP 候选判断（包括 N=1），按同一固定候选匹配标签累计 TP/FN/FP/TN，得到每目标 FNR/FPR；不是 GT-R@1、存在性错误率或 search_feasibility 的 N≥2 子集。仅重放缓存，不调用教师。
8. 子种子为 `SHA256('0|'+JSON([target,video,query]))` 前四字节的大端 uint32，调用 `numpy.random.RandomState(subseed)`。按合格轨迹的数值 ID 升序各生成一次均匀数，按真实 Y 的对应 FNR/FPR 翻转。三个模型、二分/全量对照和 Sports418 复用相同物理轨迹的噪声答案；不按排序重新抽噪声。模拟只是假设独立翻转，不声称是轨迹级教师的实测噪声。
9. T3 的问题比例是“平均提问数 / 平均轨迹数”，F1 比例是“平均二分 F1 / 平均全量 F1”，不换成逐 q 比例的平均。完美校验者全量输出真 Y，F1 必须逐 q 为1。
10. Dance 存在性标签来自完整官方过滤后 GT 是否非空，不用 Y 是否有正轨迹替代；用合格轨迹聚合分数的最大值。四种已有聚合都报告，MEAN 为主，不挑选。全部统计均为【ORACLE / GT，仅诊断】，聚合使用整条轨迹的未来帧，不是因果在线方法或真实教师加速实验。
11. bootstrap 只按完整视频聚类，2000次、seed0，FRAME/TRACK 用同一批重采样权重保持配对；AUROC 用共同 q，前缀上限用共同有候选 q。KITTI4视频只给点估计。Sports418 复用主结果的标签、分数、噪声与原45视频抽样索引，不重建一套 GT、不重推理。
