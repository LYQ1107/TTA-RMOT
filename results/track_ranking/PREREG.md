# 任务：轨迹级排序是否比帧内排序可靠（CPU-only，不调用教师，不训练）

## 0. 背景与要回答的问题
仓库 LYQ1107/TTA-RMOT，从提交 8e7d6e3 出发，新建分支 research/track-ranking-20261102。
上一轮（search_feasibility）发现：单帧之内，跨域专用模型的排序与教师判断有 35%–50% 的逆序；用 GT 当完美校验者时，“只能在排序前缀里选”这一约束在 Dance（V2-best 排序）上就让 F1 从 1.00 降到 0.52；而且每帧候选只有 5–12 个，二分查找能省的提问有限。
我们准备把搜索单位改为“视频 → 轨迹”两级：先在视频级判断这句话是否存在，再在按轨迹聚合的排序上决定哪些轨迹是目标。这一设计成立的前提是：**把分数沿轨迹聚合后，排序明显比单帧可靠**，并且轨迹数量足够多，搜索能真正节省提问。
本任务只用已封存的完整候选 margin 和 GT（只作诊断）检验这一前提。不调用任何教师或模型，不训练，不做方法实验。

## 1. 硬约束
1. 只用 multidomain_generality（01add887）已封存的完整覆盖 margin：六个跨域组合（C1 V2→Dance、C2 Dance→KITTI-V2、C3 V2→SportsMOT、C4 Dance→SportsMOT、C5 LaMOT→KITTI-V2、C6 LaMOT→Dance），以及三个目标上的同域模型（只作参照）。开始前核对全部 SHA。新增 GPU 调用为 0。
2. 本轮所有指标都使用 GT，全部标为【ORACLE / GT，仅诊断】。GT 匹配口径与 v2 相同：每帧 IoU≥0.5 一对一匹配。SportsMOT 主结果用 v4 GT，另在官方 418 条序列上重复第 5 节的判定指标作为敏感性分析。
3. 本文件的定义、聚合方式、判定规则现在固定；全部变体和全部结果都上报，不挑选，不根据结果修改。
4. 先把本文件提交为 results/track_ranking/PREREG.md 并 push，再开始计算。

## 2. 单元与标签
- 序列 q = (视频, 表达)。轨迹 τ = 该视频官方 tracker 输出中的一条轨迹，n_τ = 观测数。只纳入 n_τ ≥ 3 的轨迹，并报告被排除的轨迹数和观测数。
- 观测标签 y(q,t,τ) = 该观测是否与 q 的 GT 匹配。
- 轨迹标签 Y(q,τ) = 1，当且仅当该轨迹至少 50% 的观测 y=1（与 TRACK_ORACLE 定义相同）。
- 混合轨迹：匹配比例在 (0.1, 0.9) 之间的轨迹，记为“时变轨迹”，报告其占比（按目标、按组合）。
- 片段：把每条轨迹按时间切成长度 L 的连续片段，L = round_half_up(2 × fps)（KITTI 10fps → 20，Dance 20fps → 40，SportsMOT 25fps → 50），最后不足 L/2 的尾段并入前一段。片段标签 = 片段内至少 50% 的观测 y=1。

## 3. 三种粒度的排序质量（对每个组合的源模型 S，以及同域模型 I 作参照）
对每个有正例也有负例的单元，计算 AUROC（只有一类的单元记为未定义，不纳入均值，并报告未定义单元数）：
- FRAME：单元 = (q, t)，对象 = 该帧的全部观测，分数 = margin，标签 = y。
- SEGMENT：单元 = q，对象 = q 所在视频的全部片段，分数 = 片段内 margin 的均值，标签 = 片段标签。
- TRACK：单元 = q，对象 = q 所在视频的全部轨迹，分数 = 轨迹聚合 margin，标签 = Y。聚合方式（全部运行并上报）：
  · MEAN（主聚合方式，用于判定）：全部观测 margin 的均值；
  · MEDIAN：中位数；
  · TOP25：最高 25% 观测的均值（至少 1 个）；
  · LOGIT_MEAN：先对 margin 做 sigmoid，取均值后再变回 logit。
为了公平比较，FRAME 的结果额外按序列 q 汇总：先对 q 内所有帧的 AUROC 取平均，再在 q 之间取平均，与 SEGMENT、TRACK 在同一批序列 q 上比较（只纳入三种粒度都有定义的 q）。
同时报告每个单元的对象数：FRAME 是每帧候选数，TRACK 是每个视频的轨迹数（均值、p50、p90）。

## 4. 前缀约束的上限与搜索节省（完美校验者，诊断）
对每个序列 q，在 TRACK 粒度（MEAN 聚合）上：
- 前缀上限：在按聚合分数排序的轨迹列表中，取 F1 最高的前缀（前 k 条，k 从 0 到全部），记录这个最高 F1（轨迹级 F1，按轨迹计数）。没有正例的 q：前缀 k=0 记 F1=1。这个值表示“只能在排序前缀里选”最多能做到多好。
- 完美校验者的标准二分查找：校验者回答 Y(q,τ)，二分规则与 search_feasibility 的 BISECT_EXACT 完全相同，记录提问数和轨迹级 F1。
- 带噪声的模拟校验者：把 Y 按目标数据集的教师错误率翻转后作为回答。错误率取 decompose 探针中 CROP 方式在该目标上的漏检率（1 − 正例召回）和误报率（负例被判为 Yes 的比例），按（目标）固定，在报告中列出；随机数用 numpy RandomState(0) 按 q 派生的固定子种子。同样做标准二分查找，记录提问数和 F1。
- 对照：全部轨迹都问一遍（提问数 = 轨迹数）。完美校验者下 F1=1；模拟校验者下按翻转后的回答直接输出。
在 FRAME 粒度上用同样的方法计算前缀上限，作为对照。

## 5. 视频级存在性的可分性（只有 Dance 有空表达）
在 Dance 的每个视频内，对该视频的 17 个序列，用“轨迹聚合分数的最大值”给序列打分，计算区分“有目标的序列”与“空序列”的 AUROC（视频内计算，再对视频取平均；只有一类的视频不纳入）。源模型和同域模型分别计算。

## 6. 不确定性
Dance（25 视频）和 SportsMOT（45 视频）按视频聚类 bootstrap（2000 次、seed 0），比较 TRACK(MEAN) − FRAME 的 AUROC 差值，以及前缀上限在两种粒度之间的差值。KITTI-V2 只有 4 个视频，只报告点估计。

## 7. 预注册判定（逐字执行，规则没覆盖的情况如实描述，不新增规则）
对每个跨域组合（只用源模型 S、MEAN 聚合）：
- T1（轨迹更可靠）：若 TRACK 的平均 AUROC − FRAME（按 q 汇总）的平均 AUROC ≥ 0.05，并且 TRACK 的平均 AUROC ≥ 0.75，记为“轨迹级排序可靠”；若差值 ≥ 0.05 但 AUROC < 0.75，记为“轨迹级更好但仍不够可靠”；否则记为“轨迹级没有明显改善”。
- T2（前缀约束可接受）：若 TRACK 粒度的平均前缀上限 F1 ≥ 0.8，记为“前缀约束可接受”；否则记为“前缀约束代价过大”。
- T3（搜索节省）：报告完美校验者和模拟校验者下的平均提问数 / 平均轨迹数，以及二分查找的 F1 / 全量提问的 F1。不做判定。
总判定：
- 若六个组合中至少 4 个同时满足“轨迹级排序可靠”和“前缀约束可接受”，记为“两级搜索的前提成立”；
- 若至少 4 个组合是“轨迹级没有明显改善”，记为“轨迹聚合不能解决排序问题”；
- 其余情况记为“部分成立”，并列出各组合的情况。
同时报告时变轨迹的占比：若某个目标的时变轨迹占比超过 20%，在报告中标注“该目标需要片段级而非轨迹级的判断”。
