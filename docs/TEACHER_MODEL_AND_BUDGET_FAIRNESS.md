# 同模型、同视觉资源与预算的公平性

所有可运行对照共享固定T0模型、同BF16无量化配置、320px ROI、20%margin、同17原句/轨迹/合法历史。
T1只有官方适配器可核验时另开完整权重条件；本轮缺失不会跨T0/T1比方法收益。

| 信号 | 问题与视觉输入 | 公平对照 |
|---|---|---|
| A YES_FULL | 原版整句、当前ROI，另列官方TCP/TRP短窗口 | 最低成本原始分数不混入额外时间boost |
| B 等预算整句 | 每个属性对应一个等价完整问法，获取与C相同的ROI或四观测 | 前向数/视觉输入与C匹配，语言token实际计量 |
| C 分属性 | 动作四观测、服饰当前ROI，all-required取min | 不将UNKNOWN平均成No，不在候选轴softmax |
| D 证据验证 | C加无图、目标遮挡、等面积背景遮挡、前观测 | 与B-plus逐任务视觉和调用数匹配 |
| B-plus | 相同额外视图、等价完整问法，并使用相同Verifier | 更强的无分解控制，不故意浪费额外调用 |
| SoftMatch权重 | A原始分数与源开发固定的截断高斯置信权重 | 继承A的全部GPU成本，不称零成本MLLM系统 |

共享raw cache保存实际Yes/No logits、top token、非Yes/No标志、双类概率、输入视图/帧、token、耗时和峰值。
缓存命中只降低增量计算，不抹掉该方法所需的等价教师前向；同时报告实际worker成本和独立部署等价成本。
SQLite原始缓存共享但无GT；进程内模型和聚合状态各自独立。原模型参数版本每批检查，封存做完整参数SHA比较。
模型异常顶词不被转换成No；动作历史短缺、视觉不可验证或矛盾输出UNKNOWN，禁止硬造正例。

Gates在新目标GT评价前预注册。校准仅源四视频64固定窗口；目标GT不选择prompt、分解或门限。
由于官方大量Query-Empty并不等同于逐人逐属性穷尽人工核验，主语义Gate限定在当前帧有官方有效GT的
可评价frame-query；全部425的官方计分口径仍完整另报。空查询接受POS是“官方未匹配”，不能自动断言语义必假。
分解中动作/服饰属性没有独立属性GT，不能把完整表达GT冒充每条属性的真值；按表达类型/含属性子组报告并注明重叠。
