# ShiftRMOT-Bench-v1

This benchmark belongs to the `TTA-RMOT` repository and is separate from the
LocateMOT project. It evaluates a frozen Refer-KITTI-V2 TempRMOT source model
under controlled visual and language shifts without duplicating images.

## Data contract

The complete official V2 test set used here is `0005`, `0011`, `0013`, and
`0019`. The builder audits every expression JSON, every referenced frame, and
every referenced label before writing the manifests. `0005` is marked `dev`;
the other videos are marked `confirmation_overlap_audit`. Because these
official test videos have appeared in historical project work, the release
does not claim an unseen confirmation split.

`data/ShiftRMOT-v1/images/<video>` contains only symlinks to the external
`/data2/user/LocateMOT/data` asset store. `base_frames.jsonl` has one row per
base image and `base_episodes.jsonl` has one row per expression. The paired
condition files contain one compact row per episode/condition and retain the
shared frame index list; they do not repeat an image row for every condition.

The runtime manifest contains no expression paths, label paths, or target
annotations. `paired_conditions_evaluation.jsonl` is opened only after
predictions exist and is expanded in memory by the evaluator.

## Conditions

- **A0**: original image and original query.
- **A1**: one deterministic medium-severity visual shift with the original
  query: fog/reduced contrast, low-light/sensor noise, horizontal motion blur,
  or JPEG compression.
- **A2**: identity image and one conservative language rewrite.
- **A3**: the Cartesian product of A1 visual shifts and A2 rewrites.

Visual shifts preserve image geometry and are generated by
`rmot_tta/data/visual_corruptions.py` from the condition seed. Language changes
are a small whitelist of directional-preposition rewrites. They do not change
left/right polarity and are disabled for class synonyms, motion/parking words,
quantifiers, or negation. Every rewrite records token hashes and an audit
status.

Build and audit:

```bash
python3 scripts/build_shift_rmot.py
python3 scripts/audit_shift_rmot.py
```

The raw data, checkpoint, and generated image pixels are local artifacts and
are intentionally not committed.
