======================================================================
一、先用最直接的话回答：我们到底要做什么？
======================================================================

我们的最终任务是跨域 RMOT，也就是跨域的语言指代多目标跟踪。

输入是一段目标域视频、视频中的固定候选框和轨迹，以及一句自然语言查询。系统需要找出符合查询的人或物，并在相应的视频时刻持续输出它们的轨迹。
一句话可能指一个人，也可能指多个人；目标可能不存在；动作和位置可能随时间变化。它不是简单的“给每张裁剪图打一个分类标签”。

跨域意味着：学生原先在一个来源域学到的视觉—语言理解，到了另一个目标域会失效。例如，在 Dance 学到的模型，迁移到 SportsMOT 时会遇到不同的运动、服装、背景和目标分布。

我们允许使用目标域图片、任务查询以及教师模型的指导，但适配过程不使用目标域人工标签。人工 GT 只在方案和本研究全部预测固定、封存之后，用于隔离的评价和注明性质的事后诊断。

用户已经明确同意沿用官方固定候选框和 Track ID。研究重点是“跨域指代适配模块”，不是重做检测器和物理轨迹关联器。官方前端可能使用过目标数据集训练信息，这一点必须披露，不能把整个检测—跟踪—指代系统一概说成从未接触目标域标签。

我们希望最终获得一个统一方法，而不是六套按目标域人工指标分别调出来的规则。这个方法要有三个可清楚解释、可以独立检验贡献的创新点，灵感来自：

1. 人类如何看：先快速形成判断，遇到疑点主动观察，保持稳定的身份理解，发现变化后重新检查。
2. 经典算法为什么有效：借鉴探索与实验设计、隐状态估计、潜变量学习和交替优化的思想，把它们写进学习机制和可检验假设。
3. RSI / 双模型协同进化：一个模型的学习状态影响另一个模型如何观察和纠错，新的外部证据再推动下一轮学习；不能只靠相互同意循环强化错误。

最终对手必须是获得相同信息、相同候选、相同教师问答预算、且训练充分的普通软/硬蒸馏。我们要证明新增机制带来了额外价值，而不是只证明“用教师比不用教师好”。

目前还没有达到的终点是：在全部六个跨域实验设置中，形成可靠、实质性的优势，完成三个模块及其交互的归因，并为最终保留配方测量匹配的真实端到端成本。

三、用户设定中始终保留的约束
======================================================================

1. 适配只看目标域图片、查询、允许的源模型信息和教师证据，不读目标人工标签。
2. 固定官方候选框与 Track ID，主要研究指代适配，不偷偷给本方法更好的检测器。
3. 教师预算、输入特征、候选、查询以及必要的协议处理必须公平对齐。
4. 普通软蒸馏和硬蒸馏都要充分训练，不能用欠拟合或少信息对手制造优势。
5. 人类视觉方式和经典算法思想要进入模型学习、信息使用与反馈机制，不能只给末端调分数起一个新名字。
6. RSI 是研究方向，不能用“两模型参数都变了”“更像老师了”冒充协同进化成立。
7. 先找到有效的完整主方案，再做必要消融；不为已经失败的主方案不断扩大开关矩阵。
8. 当前只使用固定训练 seed0，不新增神经训练随机种子网格。
9. 只用 GPU 0、1、2、3，保护其他项目已有进程。
10. NAS 历史资产只读，大数据和 checkpoint 留在 NAS 或本地非 Git 目录，不上传大量权重。
11. 代码与精选记录发布到 GitHub，发布快照和可达 Git 对象均须小于 100,000,000 字节。
12. 不重启旧 80 项队列、废弃 v9 探针或重复已经封存的 v8P 六设置评测。
13. 不能因少量测试、局部正结果、队列完成、写出报告或复算 PASS 就宣布 Goal 完成。

现有 C4、Dance、KITTI 等数据都已经用于开发。用户已说明目前没有可提供的未使用划分，因此继续完成已有数据上的机制研究，但全部标为 DEV。
这意味着：可以检查每一次适配运行不读取 GT；不能把整个已经看过 DEV 评测反馈的研究过程包装成独立盲测。未见数据上的泛化证明仍然缺失。

四、我们的研究路线为什么发生了变化？
======================================================================

最初的直觉是：学生负责快速判断，大模型负责慢查证，LoRA 负责把稀疏反馈写入深层视觉特征，主动选题负责节省成本。

这个思路不是被整体推翻，而是其中几个因果解释经不起更严格的对照：

第一，LoRA 联合分支涨点，不等于涨点都来自 LoRA。重算、重新校准和输出数量变化也会改变 HOTA。
第二，按逻辑问答次数节省，不等于按真实墙钟时间节省。学生特征、模型加载、NAS 读取和图像处理都需要时间。
第三，主动选题能查到更多正确候选，也不等于整体 HOTA 必然增加。新证据如何进入学习、如何传播以及会增加多少误检同样重要。
第四，教师比较强，不意味着每条回答都适合当作请求帧上的人工真标签。教师的视角、片段范围、候选身份、遮挡和时变属性都会影响证据含义。
第五，两个模型互相反馈，并不天然得到比普通蒸馏更好的语义。它们可能只是一起更好地复制教师，也可能共同强化同一种错误。

所以后来的工作逐步转向：把证据归属、任务协议、内容与状态的关系、观察可靠性和学习反馈放进同一个可审计的机制，再与充分普通蒸馏做比较。

这不是将项目目标改成“证明 TTA 没用”。负结果的作用是排除错误解释，让最终方法更可靠；真正的终点仍是解决跨域 RMOT。

六、阶段二的 LoRA 剥离实验：确定了什么，没有确定什么？
======================================================================

C4 上做过三个关键对照：

MINUS：纯快分支，不更新 LoRA，不触发慢分支重算。
MINUS_RECALC_ONLY：关闭 LoRA 权重更新，但保留同样的固定 32 帧近似重算和重算后的快校准。
SLOW_REPLAY_MATCHED：固定问答回放，同时执行 LoRA 更新、相同重算与快校准。

实测 HOTA：
MINUS                  48.847077403
MINUS_RECALC_ONLY      50.787438101
SLOW_REPLAY_MATCHED    52.151671589

重算与再校准相对纯快分支：
ΔHOTA = +1.940360698
视频成对 bootstrap 95% 区间约 [-0.793809, 4.587253]。

匹配重算之后，再加 LoRA：
ΔHOTA = +1.364233487
95% 区间约 [-2.306727, 4.863342]，跨越 0。

LoRA 联合分支相对 MINUS：
ΔHOTA = +3.304594185，95% 区间约 [0.201004, 6.697036]。
联合结果的正区间不能替代 LoRA 与重算分别归因的检验。

固定输出数量后的排序诊断中，LoRA 的一个差值约为 -0.6095，反向数量对照约为 -0.084；不能据这些点估计写成“LoRA 普遍破坏语义”。

这组实验支持的准确表述是：
在这个 C4 设置、监督方式和重算协议下，没有拿到稳定的 LoRA 纯权重贡献证据；之前联合涨点里混有重算和数量/快校准效应。

它不支持以下说法：
——LoRA 已经被证明在所有跨域 RMOT 中无效；
——所有慢思考都无效；
——全部涨点都已经被精确分账为工程假象；
——一个跨 0 的区间证明真实效应严格为 0。

后续决定：保留慢查证这个系统职责，LoRA 暂不作为必须常开的贡献。若以后重新引入，需要在相同重算、快处理、证据和充分蒸馏之外证明增益。

======================================================================
七、阶段三的真实时间实验：我们为什么不再按调用次数吹效率？
======================================================================

用户选择了固定 C4 短切片、600 秒包含全部启动与推理的预算协议；完整 C4 另报实际成本。
短切片固定为前两个视频的前 128 个真实观测帧，选择不看 GT。未处理样本保留为空预测，不从评测分母移除。

600 秒测试中，三个策略都没有提交完成的教师反馈。时间主要被模型加载和初始特征等启动前缀消耗。
因此不能用这个实验证明哪个主动选题策略更聪明。它首先揭示了冷启动条件下的成本限制。
“三者教师调用为 0”也不等于“三者 HOTA 一定为 0”：不同策略可能有不同的未问回退和初始输出。原结果表必须按各自协议读取。

完整 C4，原定义调用上限下，每法一次实际运行：

策略          HOTA          真实墙钟秒        小时        已提交调用
MINUS_v8P     47.478252358   11229.134265      3.119204      3508
YT_PRIOR      46.091513539   10837.495066      3.010415      3508
UNIFORM_K     40.833411628    1266.149114      0.351708      3508

主动策略终点精度更高，但耗时约为 Uniform 的 8.87 倍。
完整主动运行的 initial_features 相位约 9344.021 秒，是总时间的大头；真实教师请求相位约 859.443 秒。

这说明“问答数相同”和“耗时相同”不是一回事。不能由调用数包装成全预算最高效，也不能凭三个终点就宣称得到普遍的 scaling law。

这些测量包含模型与进程冷启动，但没有清空共享服务器 OS 缓存；物理 GPU、并发顺序和 NAS 负载没有构成完整随机交叉设计。它们是本次实际运行的收据，不能当作所有机器条件下的普遍倍速。

后续小型特征流 profile 也检查了图像 IO、backbone 和 PCD 解码。在特定切片，图像 IO 占主导，512 MiB 与 8192 MiB 缓存的 backbone 次数相同，没有证明扩大缓存就更快。
NAS 可能影响读取，但任何新一轮“慢”都仍需自己的分相位证据，不能把旧实验的瓶颈归因直接复制过去。

======================================================================
八、机制诊断的第一个重要发现：框大多在，但未必被正确询问
======================================================================

历史 C4 审计中，固定前端候选可以恢复约 98.193% 的 GT 观测；把语义选择替换成逐帧 GT 参照，HOTA 约为 80.223809。

这说明：在该候选集合和评价口径下，语义选择仍有很大提升空间。不能简单把失败都归咎检测器漏框。
但这不是完美的物理跟踪器证明，也不是可部署方法。Oracle 使用 GT，只能作封存后的上界参照。

旧 C4 的 466 条真实有目标查询中，有 119 条从未问到正确候选轨迹。
122 条有目标但最终零输出的查询中，82 条属于“没有问到正确轨迹”。

这里很容易误读：119 条不是 119 条查询完全没问过。
其中 114 条其实问过别的候选，完全没有查证的只有 5 条。所以“保证每个查询至少问一次”不足以解决问题。

一句话还可能对应多个目标。看到了其中一个正确目标，也不代表这一句要求找的所有人都已经找齐。

这支持把覆盖探索作为研究重点，但并没有证明“加入一点 epsilon-greedy 就一定大涨”。后来的新证据实验实际上说明，仅增加覆盖并不自动提高总体 HOTA。

======================================================================
九、第二个重要发现：教师证据的使用方式也会出错
======================================================================

小型 C4 点诊断中，教师 CROP 原始判断的准确率约 85.25%，而一套注册的来源先验与固定二值证据组合后的判断约为 29.51%。
其中 52/61 个位置的先验 logit 已处于 ±2 截断边界，单次受限反馈常跨不过决策阈值。

这提示：来源先验、证据幅度和决策阈值的耦合可能压住有用反馈，值得检查。

但这不是“Qwen 在全数据上有 85% 的真实语义准确率”，也不是“完整 v8P 总体只有 29% 准确率”。它来自特定点集和特定简化推断。
不能把这个诊断率直接拿去设定教师权重或用 GT 调先验。

更不能因为老师在一个子集上比较准，就无条件放大所有老师答案。多视角来自同一个 Qwen，错误可能高度相关；重复问或换个视角不一定得到独立证据。

由此形成的设计要求是：明确证据对应哪个对象、哪些真实输入时刻、哪种视角；建模可靠性时写清假设；同一回答不能在训练之后又被无条件当作第二份独立证据相乘。

在后续研究中，这个问题逐步从“调贝叶斯融合权重”转向“怎样让学习目标正确理解稀疏、带噪声、有范围的观察”。

======================================================================
十、DS、多视角和存在性协议：哪些有证据，哪些仍然存疑？
======================================================================

10.1 DS 在一个历史完整 C4 回放中有价值，但不能把贡献无限外推

保留原视角流时，DS 回放 HOTA 约 48.847077，固定可靠性回放约 40.048707。
差值约 +8.798371，按 13 个原视频聚类的 95% 区间约 [2.560713, 15.826144]。

这个结果支持：在该完整回放协议中，动态可靠性与相应的证据/快校准处理，优于那个固定可靠性设置。
它不是 DS 相对所有同预算简单融合、充分蒸馏、数量匹配对手都获胜的证明，也没有把 +8.798 全部分离成纯排序贡献。

小型三视角证据库的点诊断并不一致：有的 Brier 改善，有的变差；同样三回答预算下，DS 并没有在每个设置都胜过简单均值。
因此不能把“死保 DS”理解成永远保留原实现。要保留的是“观察者也会有偏差，需要理解可靠性”这个思想。

10.2 多视角路由没有得到稳定的独立增益

同一历史 C4 回放中，原路由相对 CROP、都使用 DS 时，ΔHOTA 约 -0.305243，区间跨 0。
但视角反事实只干预了 100/3508 个回答位置，约 2.85%；不是完整线上路由策略的全面检验。
C1 的小型评估位置原路由全部选择 CROP，零差也不能被解释成路由已经有效或普遍无效。

因此，CROP 是必须保留的强基线。路由如果作为最终贡献，需要在足够实质的干预范围、同预算和同融合条件下证明额外价值。

10.3 存在性与身份不能一刀切

旧 C4 强制采用 CHECKLIST 后，HOTA 从约 48.847 降到 42.638，并错误拒绝了 48 条有目标查询。
Dance 的实际清单式协议也发生过错拒：40 条有目标查询中有 11 条被拒绝。

这说明：视频级“有没有这个目标”与候选级“是不是这个人”需要区分。
但“协议值得区分”不等于已有规则能自动泛化到任意新数据集。当前依赖元数据的协议启发仍需披露，不能当作从图像中学出的普遍协议识别器。

======================================================================
十一、为什么我们没有直接加一个重型时序模块？
======================================================================

旧 v8P 的稳定身份/成员片段中，最终输出翻转为 0。
不使用教师的学生原始打分，加 EMA 后 HOTA 从约 20.559622 到 20.834522，提升约 0.274900，95% 区间跨 0。

在那个阶段，没有证据支持“现有系统因为马上忘记而大幅失分”。盲加 LSTM、HMM 或更重的记忆网络不是优先动作。

另一个问题是物理 ID 可能混杂。旧 C1 的物理轨迹匹配观测加权纯度约 0.732；这个值是 IoU 匹配代理，含遮挡、交叉、定位和匹配影响，不等于官方 IDSW，也不是纯身份识别准确率。

如果一条 Track ID 已经串人，无条件把前面的判断传到后面，可能把错稳定住。
如果查询里有动作或相对位置，即便是同一个人，整句真假也可能变化。

后来的结论因此不是“永远不要记忆”，而是：
先分清当前模型是否真的有需要解决的时序错误，再考虑有条件地延续或重置理解。
旧 v8P 的零翻转也不能用来描述后来改成逐帧学习头的新模型。

======================================================================
十二、确实取得过的正向科研结果：两个开发设置上的协议与视觉组合
======================================================================

不能说项目至今所有实验都没有正结果。2026-11-22 的一个固定配方，在 C1 和 C4 两个已有开发设置中通过了当时的质量、组件和真实冷启动核验。

历史三个训练种子的均值：

设置   同协议充分基线 HOTA   组合 HOTA   差值       历史描述性 95% 区间
C4           67.151609       67.629222   +0.477613   [0.165546, 0.838314]
C1           32.721677       38.429592   +5.707914   [1.694525,10.591625]

这里的三个 seed 是当时已经完成的历史实验。用户后来明确不希望浪费时间在随机种子网格上，当前新增训练全部采用 seed0，不再扩展此类网格。

当时还做过更干净的组件比较：
——C1 纯视觉图边，相对同原始锚点与同 PAVA 的对手，约 +4.632923，区间为正；
——C4 真实视觉对应相对置乱对应，约 +0.561896，区间为正；
——相对简单教师回填，对应两个设置也保留了正向结果。

这些结果的意义是：特定开发任务中，协议与视觉关系的利用确实可能提供普通蒸馏之外的价值，用户的“视觉方式与经典思想”主线不是空想。

但是贡献边界也很明确：
——C1 的固定数量排序效应仍不稳定；
——C4 的图组件接近零，不是所有组件都在两个设置有效；
——协议类型与目标数据集特性相关；
——不是全六设置统一成功；
——没有证明 RSI；
——属于已有数据上的 DEV 实证。

同配方独立冷启动的 seed0 运行还报告了：
C4 同协议普通方法 66.884538 → 组合 67.437980；
墙钟约 3751.854 → 3909.972 秒。
C1 同协议普通方法 32.603390 → 组合 38.123396；
墙钟约 3002.593 → 3147.103 秒。

这些实际时间只对应这四次冷启动，不能套用到上面的历史均值，也不能套给今天的新条件状态模型。
合计有 4526 次真实教师问答、0 次缓存命中，140 个相关头的充分拟合及 1782 个查询输出文件的一致性验证。

这是一项真实但范围有限的进展。它不能作为当前更大 Goal 已完成的依据，也不能事后被改名成三个已经普遍成立的创新点。

======================================================================
十三、同样重要的负结果：我们排除了哪些看起来合理的方案？
======================================================================

我们并非只试了几次就停下。项目已经完成多种原型、机制对照、完整主实验和失败定位。以下列出会影响下一步设计的代表性结果。

13.1 覆盖探索不是单独的解药

一个新覆盖策略产生了 296 个真实新增教师回答。
未问到正确候选的查询从 122 降到 113；未得到正确 Yes 的查询从 147 降到 134。
但总 HOTA 没有稳定改善，某些运行增加约 3.4 万个 FP 观测。

这排除了“只要补问那些被漏掉的人，整体一定大涨”的过度简单解释。
覆盖仍然重要，但新证据如何变成训练目标、如何传播、怎样控制误检，必须一起解决。

13.2 更复杂的融合不自动超过简单均值

联合高斯、相关回答模式、交叉拟合潜变量等方案没有稳定超过充分对手。
二元回答存在方向可识别性问题：如果没有外部约束，仅根据模型互相一致，可能分不清哪个解释对应真实的 Yes。
多个视角来自同一模型，也不能默认它们是独立标注员。

13.3 给图传播加保护或允许不传播，也未必带来独立贡献

CUE、OPTIONAL、图保护、局部/全局选择等研究完成过官方评价与算术复算。
有的相对某个较弱对手点估计为正，但相对更充分基线区间跨 0；有的对门控本身没有独立贡献。
不能在主方法门槛失败后，把碰巧更高的 STRICT 或另一个控制组偷偷改成新主方法。

13.4 颜色、部位和单调关系等线索有局部启发，但不能包装为全局突破

部分结果包含输出数量和基率变化，强对照或固定数量后并不稳定。
“像人看衣服、看局部”必须落实成可检验的信息变化，不能靠直观命名代替实证。

13.5 双向反馈、记忆或锚点拓扑也完成过失败研究

相互学习没有自动生成新真值。两个模型共同相信一件事，仍然可能共同出错。
历史教师预测改善、神经梯度非零、目标函数下降，都没有自动转化为 HOTA 和模块贡献。

这些负结果已经保留，不会从最终报告中删除。它们的价值是约束下一次设计，而不是把任何失败都改写成“我们已经证明了一个新创新”。

======================================================================
十四、RSI 方向究竟推进到了哪里？
======================================================================

用户要求增加递归自我改进和双模型协同进化方向，并参考相关综述、TTRL、Agent0 等论文与开源代码。
这个方向已经进入当前 Goal，并进行过原文、代码与训练假设的阅读核验。相关研究记录保留在 RSI 专题 TXT 与文献/代码审计收据中。

但我们没有因此声称完成这些论文的训练复现，更没有把它们在推理任务中的结论直接移植成 RMOT 的已证实理论。

对本任务最重要的启发是：
——一个模型可以生成挑战、课程或观察建议，另一个模型通过新证据改善；
——反馈必须连接到真实任务的可观察改进；
——评价者、问题生成者和求解者之间不能通过自我赞同制造虚假的成功；
——需要区分“预测教师更准”和“追踪真实目标更准”。

在二元 Yes/No 的 RMOT 中，直接把模型多数答案当奖励尤其危险。
如果多数判断错了，两种二元选择的奖励方向都可能被反转。置信度高和一致性高都不能替代外部证据。

目前 Qwen 本体仍然冻结。我们做的是小型求解器 S 与观察/记忆模型 R 的协同学习探索。
S/R 交替更新是实际实现，但还没有证明“双方因彼此反馈而独立受益”，也没有证明这种反馈优于同样训练预算的普通蒸馏。

因此当前最准确的称呼是“受 RSI 启发的外部证据约束协同学习研究”，不是“已实现递归智能提升”。
Qwen 是否共同更新，是另一个需要单独设计、独立证据约束和公平对照的问题；没有把一次教师适配工程梯度检查算成教师进化成功。

======================================================================
十五、为什么用 DINO / PCD？它们是不是创新点？
======================================================================

当前输入沿用完整的 9352D 视觉与查询特征，既有源指代模型相关信息，也有用于外观变化描述的视觉信息。
DINO 外观相似度被用作观察变化的一项输入，目的在于给“是否仍可延续前一判断”提供视觉线索。

它不是“DINO 能直接理解整句语言”的假设，也没有独立证据证明单加 DINO 就能解决跨域。
因此对手获得相同输入和特征信息。不能把额外视觉特征只给本方法，再将收益归因为新算法。

内容路径的检查已经显示：模型输出确实对内容特征有计算敏感性。
这排除了“视觉输入根本没接入”这种工程解释，但不能证明这些特征被语义正确地使用。

用户强调要学习经典思想，而不是只用经典算法校准最终判断。于是后续重点是让视觉变化、状态延续、观察范围与反馈学习发生真实作用，而不是给某个特征提取器冠以新创新名称。

======================================================================
十六、三个首视频上有过提升，为什么仍然继续完整六设置？
======================================================================

2026-11-25 的视觉约束反馈研究，在 C1、C2、C4 各一个首视频上完成过固定主方案与多个充分对手的比较。
相对固定 MEAN_SOFT_KD，三个原始 HOTA 差约为 +8.360606、+1.177208、+0.642312。

但它仍未通过当时的严格筛查：KITTI 首视频低于若干更强对手，对全部对手的双向数量优势也没有成立。
首视频不能当作完整设置，更不能代表六设置泛化。

因此我们继续做了覆盖全部 148 单元的完整研究，而不是挑三个好看的局部结果就宣布成功。
这个决定也揭示了一件重要的事：局部正结果能提出假设，但不足以决定最终论文叙事。

======================================================================
十八、最近失败后，我们查到了哪些比“效果不好”更具体的原因？
======================================================================

18.1 旧学习目标可能要求模型同时做两件互相冲突的事

上一轮希望模型纠正带噪声的教师监督，同时又要求它在原始教师目标下的 proper excess KL 不超过 .005。
事后锚点分析给出一个乐观必要下界：129/148 个单元，在那个普通 KL 预算内，不能改正全部已发现的 canonical 冲突锚点；472 个锚点甚至单独翻转就会超出预算。

这不是“所有错误都是损失函数造成”的证明。
这个下界只针对已问点和给定监督定义，忽略了其它损失、参数耦合以及全部未问观测，不能当作 HOTA 失分的因果分账。
它确实指出：如果要学习一个有噪声、有时间范围的观察模型，就不应同时要求主方法逐点紧贴每个原始教师判断。

当前新主方法因此重新定义自己的状态/观测学习目标；普通软/硬蒸馏仍保留原来的充分拟合标准，没有把对手训练弱。

18.2 模型不是完全没有学，也不是视觉线断了

内容敏感性、神经梯度和输出变化证明图像路径确实参与计算。
上一轮在未参与训练的、已付费教师事件上，启动到最终的教师预测也有改善；独立标量复核最大误差约 4.44e-16。

然而，更能预测教师不等于更会跟踪真实目标。
模型可能更准确地复制教师的偏差，也可能把片段级回答放错到某一帧。
没有等训练/等信息的反馈对照，不能把这项改善归因为 RSI 的纯贡献。

18.3 教师回答的时间和对象范围需要建模

CLIP 看到一组实际图像，而不是抽象的某个请求帧。
同一 Track ID 内可能出现状态变化、遮挡或身份混杂。
一个“这个片段是否符合描述”的 Yes，不能未经说明就复制成该轨迹每一帧的正标签。

旧 CLIP 的实际输入大多确有多个不同帧，不能把失败简单归咎“CLIP 其实只看了一帧”。
完整有序 PCD 和相关输入也已经检查过，不能再把问题归结成无证据的截断或缺帧假说。

======================================================================
十九、当前时序、重访与空查询诊断：它和旧版有什么不同？
======================================================================

2026-11-27 针对上一轮全 148 单元、3506 查询完成了新诊断，并独立复核了 22790 个整数统计单元，最大差为 0。
这些是封存后的 CPU/GT 诊断，没有新训练、新教师、GPU 或随机种子。

19.1 当前逐帧头确实有输出变化

C4 在已匹配身份相同、同一句 GT 成员标签不变、相邻真实帧恰差 1 的 2873980 对中，主方法阈值翻转 53471 次，约 1.86%；充分软 KD 为 50688 次。

这说明旧 v8P 的“翻转为 0”不能套到新模型。
但翻转并不自动等于错误，也没有单独证明引入记忆就会涨分。

19.2 全轨迹均值很强，但不能假定每条轨迹整句永真

轨迹均值是必须保留的简单强基线。
同时，同一候选 ID 的 canonical 成员会混合。把整 ID 强行设为一个常数，仍会产生逐行成员错误。
这些混合可能来自动作/方位变化、可见性、匹配和身份混杂，不是纯动作变化的准确计数，更不是 HOTA 上界。

19.3 当前零输出问题已经不是旧版的同一个量级

上一轮主模型的“有目标却零输出”查询，在 C1..C6 为 0/7/1/1/0/0。
因此不能继续把历史 C4 的 122 条零输出直接当成当前主模型的错误账单。

19.4 真空查询和 canonical 零匹配必须区分

按官方评价核验，C1/C6 各 425 条查询中有 385 条官方真空查询；C2/C5 各 862 条均有官方目标，其中 7 条没有 canonical 正观测；C3/C4 各 466 条均有目标。
这些 GT 得到的占比只用于诊断，不进入适配先验或阈值。

上一轮主 C1/C6 在真空查询上分别输出 209810/196577 个 FP。
这支持把视频存在性与身份判断放进统一模型，但不支持用这些 GT 占比直接设置部署先验。

19.5 重访会带来变化，也会反复矛盾

六设置主动历史共有 9726 次同 query/候选 ID 重访，1963 次教师硬答案翻转，其中 1832 次 canonical 成员不变。
这说明重复观察不总是获得新的真实状态变化，也可能遇到教师波动或观察条件差异。

不能由此宣布所有重访都浪费。负证据、歧义消解和多目标发现仍可能有价值，要通过固定问答对照验证。
当前目标是学会“什么时候沿用已有判断，什么时候值得重看”，而不是机械地禁止重访。

======================================================================
二十、当前正在验证的新主方法：条件状态学习是什么？
======================================================================

名称：CONDITIONAL_STATE_MEMORY。
它是对新旧框架的部分整合，不是旧 v8P 完整系统已经全部回接。

模型分为两个主要学习部分：

S：求解器。根据视觉与查询形成当前节点的匹配倾向 p_t。
R：观察/记忆模型。根据实际可观测变化，形成延续旧状态的概率 r_t，并参与教师观测通道的学习。

用简化公式表示状态转移：

P(z_t=b | z_(t-1)=a)
  = r_t × I(a=b) + (1-r_t) × Bernoulli(b; p_t)

用人话说：
如果现在看起来仍然是同一个稳定情况，允许保留前面的理解；
如果外观、几何、查询相关视觉或时间关系显示情况发生变化，就重新根据当前视觉判断。

重要区别：它不是把“这条轨迹有人”直接当作“这个人每一帧都符合整句”。

R 的变化输入包括时间间隔、DINO 外观相似度、查询相关 PCD 相似度、几何/大小变化和静态/动态等可观测标记。
这些特征不保证能识别所有串人或动作变化，它们只是模型可以利用的观察线索。

20.1 教师不是无噪声真值

不同视角用可学习的敏感度/特异度通道描述。
信道被约束在 .5 到 .99 的朝向范围，是“观察者总体正向”的建模假设，不是已从无标签数据唯一识别出的语义真值。
同一个 Qwen 的多次观察仍可能相关；当前模型没有证明所有条件独立假设都满足。

20.2 CLIP 只作为一次有范围的观察

每个 CLIP 事件在它实际提供的不同输入时刻之间引入潜在时间归属；不因重复图像或名义帧号把一条回答扩成多份独立证据。
使用的是结构化变分目标，不冒称已求出真实 CLIP 语义的精确边缘概率，也没有证明教师对片段一定采用“某一帧为真”的含义。

20.3 存在性协议进入状态模型

CHECKLIST 允许视频级不存在，使用登记的 .5 存在先验。
PRESUPPOSED 固定视频级存在。
两者都不强迫任意候选、任意帧或任意一个人必须为正。

20.4 学习目标改变，而不是只把后处理换名

S 学习重置正/负状态的期望充分量；不是把所有时序后验照搬成逐帧伪标签。
R 学习延续/重置关系及观测通道。
完整目标包含结构化决策 ELBO、AUX 软监督和登记的记忆/信道正则。
主方法不再被原始教师逐点 .005 KL 约束锁死；普通蒸馏继续满足自己的充分拟合标准。

20.5 经典思想与 RSI 的边界

它借鉴隐变量、状态推断和交替优化，将思想放入训练机制。
EM、状态估计和选择性更新本身都有既有研究基础，不能只换名就当成论文创新。
参数变化、目标下降、回溯接受和数学检查通过，都不等于语义变好或 RSI 成功。

二十一、当前主方法怎样训练，为什么这次普通蒸馏不再是弱对手？
======================================================================

当前登记固定：
——完整 9352D 输入和同架构 288 隐层普通头；
——从原先已经充分训练的 UNIFORM_SOFT_KD 初始化；
——四轮，每轮 S 尝试 1500 步、R 尝试 1500 步；
——合计 S/R 各 6000 尝试步，学习率 .0001；
——固定 seed0；
——每轮 8192 个均匀 query-observation 样本加已问锚点，并记录相应权重；
——完整目标回溯分数固定，不按目标 GT 接受更新；
——保存完整轮次状态和 RNG；未完成轮次从最后有效状态继续。

“6000 尝试步”不能自动写成“6000 次非零、有效且被接受的语义更新”。回溯可能接受缩小步长或退回，实际收据保留这些情况。

三类新的普通头各自从相同已充分初始化继续训练：
SOFT_KD：保留教师概率的软蒸馏。
HARD_KD：教师二元判断的硬伪标签学习。
FUSED_KD：将同一观察模型融合得到的监督交给普通头学习。

它们各自额外至少 6000 步；若未满足原登记目标，可继续到最多额外 16000 步。
充分性标准仍为各自声明的 proper excess KL/对应目标差不超过 .005。
因此每个普通头包含继承训练，总计至少 12000 步。
本轮核验了 444 个这样的普通拟合，均满足登记要求。

“普通蒸馏”和“强蒸馏”不是两种必须对立的新学术任务。
这里所谓“强”，主要是指普通对手获得完整公平信息、合理容量、充分拟合和同等必要处理。
一个故意少训练、删特征、不给协议或少给回答的蒸馏，只能称弱实现，不能用来证明我们的机制有价值。

如果同样信息的普通软蒸馏已经很强，这是公平性要求，不是应该压低的障碍。
本方法应通过更合理地解释观察、利用未标注视觉结构和形成有效反馈来超过它。

二十二、七类主对照和三类保留对照：分别排除什么假象？
======================================================================

主研究的七个对手：

1. SOFT_KD：相同信息的充分软蒸馏。
2. HARD_KD：相同信息的充分硬蒸馏。
3. SOFT_POOLED：充分软蒸馏后做轨迹汇聚，检验简单稳定化能做到多少。
4. SOFT_SHARED_MEMORY：软蒸馏接同一个最终 R、任务协议和证据读出。
5. HARD_SHARED_MEMORY：硬蒸馏接同一个最终 R、协议和读出。
6. FUSED_KD：用相同范围与观察模型形成融合监督，再交给普通头。
7. FUSED_SHARED_MEMORY：融合蒸馏再接同一个最终 R。

共享记忆对手刻意获得本方法最终 R。这是偏强的机制对照，用来防止把一个好的读出器效果全部算成 S 的学习贡献。
FUSED_KD 也使用学习到的 R，因此不是完全独立、未经本方法帮助的纯教师真值，报告中必须披露。

另外保留三个原先已经充分、没有继续补训的对手：
PARENT_SOFT_KD；
PARENT_POOLED；
PARENT_SOFT_SHARED_MEMORY。

原因很实际：继续训练有时也可能改变甚至损伤一个原本很强的基线。不能只保留补训后的对手，把原来的充分对手删除。

这三个保留对手没有新增拟合、教师调用、候选或随机种子。
使用保存的最终 R 做数值忠实回放时，已有共享记忆概率最大误差约 1.25e-8，阈值 mask 变化为 0。
这是数值一致性证据，不是 HOTA 增益。

对每个比较都包含原始输出和两个方向的数量匹配：
——把主方法限制到对手的逐 query/frame 输出数量；
——把对手限制到主方法的逐 query/frame 输出数量。

这样可以检查收益是否只来自阈值、基率或多输出了一些框。
CountMatched 是诊断性反事实，不是部署时使用 GT 的新方法，也不是 HOTA 因果分解的全部答案。

二十六、旧快慢思考和新方案应该怎样结合？
======================================================================

没有理由把旧框架整体抛弃。完整系统仍应是：

快速识别 → 发现疑点 → 主动取得有用观察 → 在正确范围内记住 →
证据修正学习 → 当前学习状态指导下一次观察。

当前新方法继承了：
——官方学生、固定候选与任务查询；
——原始真实教师问答和实际输入范围；
——CHECKLIST / PRESUPPOSED 任务协议启发；
——观察者可能有偏差，需要建模可靠性的思想；
——快判断与慢查证的职责分工。

当前尚未完整回接：
——旧主动覆盖和疑点触发选题；
——完整的在线多视角决策；
——原版 DS 的具体实现；
——LoRA 权重适配分支。

其中，DS 的思想已经被新可学习观测信道部分继承。不能再把同一回答的原 DS 后验叠上去，冒充另一条独立证据。
LoRA 不作为必需常开的模块，保留历史实现与负结果；以后若接回，要证明额外贡献。

当前固定 UNIFORM 问答只检验“拿到相同证据后，是否学得更好”，没有证明新的主动选题贡献。
因此，这一版是部分整合，不是完整旧系统与新模型的全部组合。

本轮保持登记代码不变，是为了保留这一问题的可解释性；当前实验中途加新选题或 LoRA，会同时改变信息、训练和成本。
下一版完整组合应根据完整结果固定，不能永远停留在各自独立的小原型。

三十、成本问题还缺什么？为什么今天的等待不等于部署很慢？
======================================================================

今天正在等待的是使用人工 GT 的事后官方评价，属于科研验收时间。
它不计入部署时算法的无标签适配成本。需要公平报告研究运行消耗，但不能把 CPU 官评耗时直接算成模型上线推理延迟。

当前已经做过一个冻结 27 个完成收据的训练前缀相位审计，核对了 S、R、普通拟合、输出封存等时间。
这是已付费特征、教师问答和原充分 KD 初始化之上的新增成本。
它不是从原始输入重新启动全部模型的 fresh 成本，也不是整个并行实验的总历时。

多个视频单元墙钟之和，不等于使用四卡后的实际结束时间；进程占卡墙钟，也不等于纯 GPU 核函数积分。
数据 IO、CPU 推断、状态计算、反向传播和输出落盘需要各自打点，不能看到一个大 residual 就认定“肯定是 NAS”或“肯定是 GPU 算不动”。

过去 profile 可以证明某个已测切片的 IO 很重，却不能替代新配方的完整分相位测量。
NAS 读取与共享主机负载必须如实说明；缓存复用如果是性能来源，也要作为工程条件单列。

最终成本实验应至少同时回答：
——首次请求要多久？
——教师实际前向多少次，缓存命中多少？
——学习和状态更新用了多久？
——共享特征和预训练头是否预付？
——同预算下本方法与充分蒸馏的精度差是多少？
——额外收益是否值得额外真实时间？

目前没有证据宣称最终新方案已处在所有预算的最优 Pareto 前沿。

三十一、公平性和统计解释：本项目必须持续避免的误读
======================================================================

1. Native 不是教师蒸馏基线。
   用老师比不用老师高很多，不等于新的状态/反馈模块贡献很大。

2. 充分拟合不是语义正确。
   KL 达标说明网络能拟合声明的训练目标，不说明教师标签或目标本身正确。

3. Oracle 不是部署结果。
   完美语义上界用 GT，只能说明候选内存在空间。

4. canonical 匹配不是纯语义真值。
   它混合框定位、可见性、身份、匹配与片段归属，不能直接命名为“Qwen 语义准确率”。

5. 同一模型多视角不自动独立。
   重复输入、同图全景与裁剪、同一物理轨迹或字面别名必须追溯。

6. 固定数量改善也不是全部机制真相。
   CountMatched 有助于控制数量混杂，但不能代替全部时序、匹配与数据分布分析。

7. HOTA 不能简单取逐视频均值。
   当前官方充分统计按 TP 加权的 AssA 及 TP/FP/FN 聚合，在固定评价阈值上复算。

8. 两模型一起变好不证明相互促进。
   训练步数、数据量和学习目标同时变化时，需要额外反馈对照。

9. 局部和完整结果不能互相替代。
   首视频、两个开发设置、完整六设置是不同证据范围。

10. 全部 DEV 不等于无价值，但不是独立泛化。
    后续论文必须注明开发过程；不能把按这些指标做过选择的方案冒称首次盲测。

11. 差值跨 0 不证明真实效应严格为零。
    负结果要求收缩主张，不授权泛化为“某算法在所有情况下无效”。

12. 点估计刚好为正不等于用户要求的大幅提升。
    需要看实质幅度、查询/视频稳定性、数量控制、模块证据和成本。

三十四、十个最容易关心的问题，直接回答

问：目标还是跨域 RMOT 吗？
答：是。没有改成写负结果综述，也没有放弃目标域无标签适配的设定。

答：完整视觉、同一批教师证据、合理容量和充分训练本来就应给普通对手。我们需要超过这个对手，而不是压低它。

问：旧快慢思考是不是全错了？
答：不是。快判断—慢观察—证据修正的职责仍保留。没有稳定贡献的是部分具体实现和过去过度的因果解释。

问：是不是再加个大模型、LoRA、记忆网络就行？
答：现有证据不支持这种保证。先明确证据范围、监督目标和反馈如何产生新信息，再判断需要什么模块。

问：现在是只改公式，还是在学习？
