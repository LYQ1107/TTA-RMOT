TTA-RMOT：从人类视觉方式与经典算法思想出发的理论设计
2026-11-22；候选方法设计与理论边界，尚非三项新机制的完成验收

一、这次纠正意味着什么

研究目标仍是跨域 RMOT：给定目标域视频、语言查询和官方固定候选框/Track ID，
用冻结教师提供稀疏指导，不用目标域人工标签训练、选题或选择参数。
目标人工标签只在本项研究全部原始及数量控制输出封存后用于隔离评价。
已有数据全部是开发数据，没有未使用的独立划分。保留这一事实。

“人类视觉本能与经典算法”不是把人类比喻贴在 DS、PAVA、图传播三个算法上。
我们应先从跨域 RMOT 的失败机制提出问题，吸收经典思想，构造任务所需的
变量、目标和信息流，然后证明设计具有哪些性质，最后用实验核查性质是否
解决了实际问题。经典定理是依据，不是我们发明的定理，也不是涨分保证。

三个候选创新点必须构成一个共同框架，在六个跨域实验设置中验证；不是每个
设置设计一套方法。暂定的三条主线是：

I1：覆盖与疑点共同驱动的主动观察——决定有限预算应该看哪里。
I2：相关性受控的证据推理——决定哪些反馈是新证据、能改动多少判断。
I3：视觉与语言关系约束下的结构化适配——让各个局部判断彼此相容。

此处名称只是研究主线；是否最终成为论文贡献，由相应实现、对照与结果决定。
本文件没有把正在运行的旧配方改名后宣布为新方法，也没有修改其数值代码。

二、共同问题与普通教师蒸馏的关系

记 i=(q,t) 为查询 q 与候选轨迹 t 的配对，x_i 是冻结学生提取的视觉信息，
u_i 是充分训练的普通教师伪标签头输出，p_i 是我们最终需要得到的指代信念。
候选集合可能漏检、串 ID，语义也可能随时间改变，不能假定前端完美。
老师一次回答记为 e=(q,t,v,f)，其中 v 是视角，f 表示实际输入帧/片段及提示。
回答 t_e 属于 [0,1]，不是人工真值。普通蒸馏与新方法得到相同实际问答。

普通蒸馏已经会学习特征、跨轨迹泛化，并可对整条 Track ID 传播结果。
不能故意把它限制成逐帧复制一个 Yes/No，也不能让它欠拟合来制造优势。
新方法可能增加的价值，是安排更有覆盖性的观察、抑制相关错误证据、利用
经过审查的视觉/语言关系；这种价值必须分别证实，不能由“使用经典算法”推出。

一般情形下，不存在我们的框架必然优于充分蒸馏的定理：老师可能已完美，
结构关系可能错，候选也可能已经限制了上界。理论应说明适用条件和风险。

三、I1：学习覆盖、边际收益递减与主动感知的思想

人的观察不是只盯着第一眼最像的人，而是先形成场景覆盖，再集中查看疑点。
对应到任务，不能只按学生分数最高或熵最大反复提问。需要区分：
“尚未看过的合理候选”与“同一个候选的重复确认”，以及“同义问题的重复花费”。

一种可分析的批次设计如下。构造尚待解释的单元 i；其权重 a_i>=0 来自
无标签的查询覆盖、视觉候选分层及上一轮结构残差，而不是 GT 错误率。
候选观察动作集合为 E，k_ie∈[0,1] 表示动作 e 对单元 i 的覆盖程度。
一次动作直接观察谁、能在明确同义关系下复用到谁，都应在该核中明确。
相似外观不等于相同身份，不允许未经检验就把一个 Yes 当成一群人的标签。

冻结一个观察批次中的 a_i 和 k_ie，定义覆盖目标：

  F(S) = sum_i a_i max_{e∈S} k_ie，F(空集)=0。

它体现的思想是：第一眼补上空白的价值通常大，重复看已有相同证据的价值小。
如果认为第二个视角能排除第一个视角的歧义，应把它编码为不同的待解释单元；
不能在证明后任意把 F 换成非次模的“协同信息增益”，仍沿用同一保证。

性质 1（经典次模结论的任务化实例，不是新定理）：
当 a_i>=0、k_ie 固定、动作等成本、预算是最多 B 个动作时，F 单调且次模。
逐次选择最大边际增益的贪心集合 S_B 满足：

  F(S_B) >= [1-(1-1/B)^B] F(S*) >= (1-1/e) F(S*)。

证明：令 m_i(S)=max_{e∈S}k_ie。加动作 e 的增益为
sum_i a_i max(0,k_ie-m_i(S))。若 S⊆T，则 m_i(S)<=m_i(T)，所以增益递减。
次模性给出 OPT-F(S_j)<=B·最大剩余边际增益；贪心每步至少缩小 1/B 的
剩余差距，递推 B 次即得上式。若预算未用完就所有边际增益为零，则已最优。

这只保证覆盖代理目标，不能写成覆盖了 63% 的真正目标，更不是 HOTA 保证。
带正权重的轨迹单元仍可能选不到真目标；覆盖核本身是否合理要做实验。
多视角真实时间不同，简单“增益/秒”贪心不能直接套上述等成本保证。
冷启动和同批推理也不具有简单可加成本，真实墙钟时间须另行实测。
若回答后更新权重，本证明只对每个冻结批次成立；全程自适应近似保证需要
额外的自适应次模条件，目前没有证明，不能声称已经成立。

理论应指导实现：覆盖对象、动作和冗余定义必须一致；先覆盖后细看不等于
随便加一个 epsilon-greedy 比例，更不能靠 GT 找到最佳探索率。

四、I2：学习稳健估计、有限影响与相关证据的思想

同一位老师对相同图像换种问法，并没有自动变成两个独立可靠的证人。
同一模型的 CROP/FRAME_BOX/CLIP 也可能共享偏差。重复相乘似然会造成虚假确信。
DS 可以作为一个估计工具，但它的隐含独立性、可辨识性并不会因模型名字而成立。
无人工标签、重叠稀疏、视角相关时，不能把 DS 拟合参数称为实测教师准确率。

拟议的任务设计是为证据定义组 g，并限制每组的总影响。完全相同的请求签名
应先去重；组内不同帧或视角保留区别，但归一化权重之和不超过一。
签名至少包括模型版本、查询/提示、真实帧或片段、裁剪框和视角；仅 query+Track ID
相同不足以认定是重复。完全相同输入的随机多次回答，若要视作重复采样，也必须
另有固定规则，不能同时宣称“保留全部随机采样信息”和“复制完全不影响结果”。

可分析的信念更新采用稳健风险而非伪装成独立观测的 Bayes 连乘：

  E(p) = (mu/2)||p-u||²
       + sum_g omega_g sum_{e∈g} alpha_ge rho_delta(a_e^T p-t_e)
       + lambda_v Omega_v(p) + lambda_s V_s(p)，p∈[0,1]^n。

mu>0；omega_g>=0；alpha_ge>=0 且组内和<=1；||a_e||<=1。
rho_delta 是 Huber 损失：|r|<=delta 时 r²/2，否则 delta|r|-delta²/2。
Omega_v 与 V_s 是固定的非负凸视觉/语义关系惩罚，下文说明适用条件。
a_e 可以只取被观察单元，也可以按事先确认的等价映射取线性组合。

u 与 t_e 可能来自同一批教师回答。因此第一项是保留充分蒸馏结果的正则，
不是与第二项独立的“新先验样本”；不声称统计证据量翻倍。
组权重或图由无标签信息估计后，在一次求解内固定，才能应用下面的性质。

性质 2a（条件唯一性）：
上述条件下 E 在非空紧凸盒上 mu 强凸，因此最优 p 唯一。
这消除了这一信念求解子问题的多解，不保证上游神经头训练全局最优。

性质 2b（单组证据的影响有界）：
固定 u、其它证据及结构项，只加入一个权重 omega 的证据组。设旧解 p、
新解 p'。因 Huber 导数绝对值<=delta 且组内权重和<=1，该组梯度范数
最多 omega·delta，于是：

  ||p'-p|| <= omega·delta/mu。

证明：强凸函数加盒约束的最优性条件可写为梯度与法锥之和为零。
两次条件相减并与 p'-p 内积，用强单调性及法锥单调性可得
mu||p'-p||² <= ||该组梯度||·||p'-p||，除去零向量情形即得。
用一个同样有界的新组替换旧组，上界相应为 2omega·delta/mu。

这是“少量不可靠反馈不能无限推翻已有信念”的可解释性质，不是教师纠错率。
如果 u、组权重或图也随该组改变，以上界仅适用于冻结它们的条件更新；
不能把它写成整个深度适配流程的稳定性定理。实际实现须测量各部分的改变。

性质 2c（严格去重后的复制不变性）：
当输入证据先按完全相同签名形成集合，并且 u、结构与权重也只依赖这个去重
集合（或保持固定），复制同一条记录任意次数不改变目标函数，所以不改变唯一解。
如果上游神经头仍按未去重的记录训练，这个整个流程的复制不变性就不成立。
仅仅“按视角求平均”不一定具有这个性质：若一组含不同回答，单独复制其中
一个仍会改变均值。当前多视角对照使用组均值，尚不能宣称已实现此性质。

这里的候选创新不是“用了 Huber 或 DS”，而是与任务观察单元一致的分组、
影响分配、协议条件以及结构反馈方式。Huber 和凸优化是实现这些原则的工具。

五、I3：学习约束推理、关系一致性与最小改动的思想

人的判断会互相检查：同一对象同时满足“白色 T 恤”却完全不满足“白色上衣”，
可能是局部判断不一致；看起来相近的两个人却不一定是同一个身份。
我们需要任务正确的关系，而不是无条件平滑或“同色就属于同一查询”。

高可信的、语义范围一致的包含关系可写为 p_A<=p_B；明确等价可写 p_A=p_B。
查询中主语、颜色指向、否定、位置参照和时间范围必须一致。含糊描述不强行建边。
“white shirt next to a black car”的 white 不能误绑定到 car；运动员角色也不能
由场景名直接推出。文本解析支持率不等于正确率，已有审计只能说明适用范围。

视觉关系可采用非负图权 w_ij，并定义
  Omega_v(p)=(1/2)sum_ij w_ij(p_i-p_j)²。
它是凸的，但“应该接近”仍是建模假设。错误邻居或串人的 Track ID 会传播错误。
可疑视觉边更适合作为有限权重软约束，而非强制相等。
任务协议也必须保留：PRESUPPOSED 与 CHECKLIST 对不存在的容许性不同，
不能把“对几个候选回答 No”直接当成整段视频无人符合查询的证明。
协议不是数据集名称；目前协议和目标数据集重合，不能由现有实验独立识别两者。

性质 3a（关系正确时的最小改动性质）：
令 C 为非空闭凸约束集合，p=Pi_C(u) 为欧氏投影。
若真正的成员向量 y∈C，则有：

  ||p-y||² <= ||u-y||² - ||p-u||²。

证明：投影的变分不等式给出 <u-p,y-p><=0，展开 ||u-y||² 即得。
它说明满足正确关系的平方误差/Brier 风险不会变差，不需要在适配时看到 y。
但这是给定关系正确的条件结论；没有证明所有文本边、视觉边都正确。

性质 3b（关系有误时，风险项显式出现）：
若 y 不一定在 C，令 z=Pi_C(y)，d=||y-z||，则同样展开可得：

  ||p-y||² <= ||u-y||² - ||p-u||² + 2||p-u||d。

其中 d 衡量关系与真值的不相容性；错误关系可能抵消乃至超过修正收益。
不能在推理时用目标 GT 计算 d 或选择约束，只能封存后将它作为诊断。

性质 3c（软约束下的同类界）：
若 V 是非负凸关系惩罚，
  p=argmin_{p∈[0,1]^n} (1/2)||p-u||²+lambda V(p)，
对任意盒内 y，强凸最优性给出：

  ||p-y||² <= ||u-y||² - ||p-u||² + 2lambda[V(y)-V(p)]。

例如 V=sum_ab c_ab[max(0,p_a-p_b)]²，c_ab>=0。
若 V(y)=0，平方误差不增；若真值也违反关系，就明确付出 V(y) 的代价。
证明：将 y 代入一强凸目标的最优性下界，展开并移项即可。
这条性质仅对这里定义的近端子问题成立，不应套到任意多步拼接或整个 E。

HOTA 还涉及阈值、输出数量、定位与关联匹配。因此平方误差改善不能推出
HOTA、AssA 或所有查询必然改善；必须同时报告原始结果及双向 CountMatched。
二元查询成员向量是否真满足所有关系，只能在隔离诊断中检验。

六、三项如何组成一个方法，而不是三个零件

同一个查询—候选关系表示应贯穿观察、证据与结构推理：

  冻结学生与候选 + 查询
       -> 建立保守的视觉/语言关系与初始 u
       -> I1 在固定批次中优先填补覆盖空白、选择新的判别证据
       -> 冻结教师回答进入 I2，去重、分组并限制影响
       -> I3 用关系约束协调局部信念
       -> 本轮残差和未覆盖部分用于下一观察批次
       -> 统一解码，输出原固定 Track ID 的指代结果。

I1 的“新证据”定义必须与 I2 的证据组一致，否则会用预算买同一个信息。
I3 发现矛盾可以触发进一步观察，不能只靠平滑把矛盾抹掉。
I2 需要给出可撤回的弱证据，不能把一次错误 Yes 永久硬编码成关系真值。
批次之间允许更新，但每个性质的冻结条件必须满足；跨批次全局收敛或性能
保证尚未建立。当前视频转导、过去/当前视频前缀可用，不冒称逐帧在线。

因此论文可能的任务贡献是：围绕跨域指代的稀疏、相关且有偏的教师反馈，
联合设计“观察机会—证据影响—关系约束”，减少漏看与自相矛盾。
是否有足够新意，还须与原始相关研究比较；本文件没有完成创新性检索。

七、理论应该怎样被实验检验

先确认正在运行的六设置机制实验与基线结果，不因这次文字纠正取消有效运行。
下一版若实现上述统一目标，必须在看其 GT 前固定代码、所有参数规则和分析。
所有条件共享同信息、候选、实际教师调用预算、充分头训练和统一解码。

I1 对照：相同预算的均匀、仅初始分数、仅不确定性、覆盖与疑点组合。
每种策略收集到的问答也单独交给同一普通蒸馏头。这样才能区分“问得好”
和“问完处理得好”。不能把别人没获准请求的 SQLite 答案白送给自己。
观察覆盖代理值、真正目标被询问情况及 HOTA；后两者仅封存后评价。
已有 SEARCH 说明覆盖改善仍可能因误报而降低总 HOTA，不能预设结果。

I2 对照：相同问答、相同结构下的直接原始教师回填、充分软/硬蒸馏、
普通平均融合、当前可靠性融合以及拟议的相关性受控更新。
必要诊断是重复记录注入、有限比例冲突证据与逐组影响；扰动条件只作
机制诊断，不替代未扰动主结果。复制不变和梯度上界须按实际代码核验。

I3 对照：同一 unary、同一问答、同一解码，去掉结构、只视觉、只语义、
完整结构；另设同强度置乱边或错误关系对照。报告支持/不支持的查询分层。
例如外观单属性、外观与位置组合、运动、角色、其它，分层仅由查询预定义。
约束满足率只是机制指标，可能把所有概率推成一样而虚假改善，不能代替 HOTA。

三模块整体：完整方法、逐项拿掉 I1/I2/I3，以及需要的交互对照。
改变 I1 后让普通蒸馏获得该条件相同问答；固定问答研究 I2/I3；分别解释。
非线性 HOTA 的增益不能把三个单模块涨幅相加。每个保留模块须有适用场景
的独立或交互贡献，不要求每个模块在每个设置单独上涨。

六设置 C1 V2→Dance、C2 Dance→KITTI-V2、C3 V2→SportsMOT、
C4 Dance→SportsMOT、C5 LaMOT→KITTI-V2、C6 LaMOT→Dance 用同一方法规则。
主要比较是公平普通蒸馏及教师回填，而不是只和低分 Native 比。
使用神经种子 0/17/42，分开数量修正与排序贡献，保留所有负结果。
KITTI 仅四视频，不作可信的总体置信区间推断；其余开发集区间也只是描述性。
最终保留实现必须重新实测真实冷启动、特征、问答、拟合、推理与总墙钟时间。
固定证据回放不是零成本部署，更不等于全预算下优于普通策略。

八、已有实验到底支撑到了哪里

已完成的两设置中间证据：同一充分教师头下，C4 普通 Final 为 67.151609，
已有最小组合为 67.629222，约 +0.477613；C1 为 32.721677→38.429592，
约 +5.707914。C4 视觉对应对置乱、C1 跨候选汇聚有条件贡献。
这些是特定实现、特定开发设置的结果，不是本文拟议统一能量目标的结果。
C1 排序收益仍不稳，C4 没有解决所有查询漏找，不能说整个研究目标已经完成。

正在执行的六设置迁移、查询关系一致性、多视角证据研究会提供基线和机制
信息。它们不等于上述新三机制已经全部实现：
  - 当前覆盖策略不是此处 F 的贪心实现，不能引用 1-1/e 作为它的保证。
  - 当前 DS 不是 Huber 分组有限影响目标，不能套用性质 2b。
  - 当前同视角组均值不是严格签名去重，不能套用复制不变性。
  - 查询凸投影子问题可讨论性质 3a，但需核查实际投影集合及求解误差；
    其它拼接步骤的整体效果不能一并由这个子问题定理保证。

旧 LoRA 剥离不支持稳定纯权重收益，并不意味着任何深度适配都无效。
过去“0 次输出翻转”也部分来自 Track ID 级固定输出，不能冒充人类记忆机制
已经完善。未发现主要时序收益证据时，暂不盲加 HMM 或新的记忆网络。
“人类视觉”提供设计启发，当前没有人类实验来证明系统复现了生物视觉。

九、论文可以写什么、还不能写什么

可以写：从覆盖、稳健有限影响、结构约束思想提出任务机制；对明确子问题
给出带条件的优化性质；用同预算对照说明何时比普通教师学习更有效。
可以把负结果作为设计依据，解释为什么不依赖盲目权重更新或无条件判空。

不能写：我们发明了次模贪心/Huber/凸投影；只要用三个经典算法就有创新；
定理证明 HOTA 必然提升；DS 已测得教师真实准确率；复制均值等于信息独立；
每个模块每个设置都有效；六设置已经可靠胜出；所有预算都更快；开发后结果
是独立盲测。也不能把当前未实现的框架写进已完成方法卡。
