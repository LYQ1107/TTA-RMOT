# PSR 失败与限制记录

2026-10-29，目前无正式PSR RMOT结果，不预先宣布成功或失败。

1. 40Train图像41796/表达1560已在，但同配置预测MOT0/40；官方发布的DETR-NeuralSORT-Dance仅25Val。
   iKUN作者issue35/44明确NeuralSORT/NKF代码未发布，无法由公开代码精确恢复；未使用GT或替代检测器。
   用户随后明确改为现有Val执行，记录协议改变，不伪装正式Train→Val。
2. CLI HTTPS push缺凭据，连接的GitHub发布接口可用。逐blob/整tree核验后发布，不能把本地commit当成远端成功。
3. 当前PSR发现657个教师高分判断 vs Naive656，Full新增254弱观测；这些不是真实正例或正确传播数量。
   五角色在固定锚点候选子池内覆盖轨迹，不保证预算能覆盖全部短生命周期轨迹。
4. 两端完整表达POS及中间RGB稳定只支持有限弱插值，不证明中间动作未变，也不证明预测ID没有发生同色人物漂移。
   所有表达含动作/混合语义，只扩展一帧，不作长轨迹永久身份/存在性标注。
5. 24,576参数容量保持不变；不因结果不理想就为PSR单独增大容量或按目标GT改阈值。
6. 共享GPU和跨策略raw缓存导致实际耗时不同；各方法逻辑预算8500相同，完整required成本与当前实际前向分列。

只有预测完整封存后的GT审计能判断错误来自教师、采样、拟合、扩展还是最终选择；届时保留全部正负结果。
