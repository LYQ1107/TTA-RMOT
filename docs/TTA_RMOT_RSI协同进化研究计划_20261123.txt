1. 用户指定的文章
What if automating AI R&D triggers an intelligence explosion?
https://arxiv.org/abs/2609.36054
https://arxiv.org/pdf/2609.36054

已核对原始PDF。文章讨论改进后的AI重新投入科研、进一步帮助改进AI的反馈循环，也讨论计算、数据和实验周期等限制。它是研究动机的来源，不是一套可直接复制到RMOT的训练算法，更没有证明视觉模型只要互相训练就一定进步。我们借鉴的是“改进学习过程本身，再用新的学习能力改进下一轮”的思路。

2. 最贴近“双模型相互进化”的技术参考
R-Zero: Self-Evolving Reasoning LLM from Zero Data
https://arxiv.org/abs/2508.05004
https://arxiv.org/html/2508.05004v1

该工作交替优化Challenger与Solver；出题难度由当前Solver决定，Solver再利用筛选后的自生成任务学习。其训练伪标签含自身多次回答的多数票，不是外部正确答案。我们借鉴动态课程和双向反馈，不把多数票或低自一致性直接当成视觉任务的真值与学习价值。

3. 关于反馈为什么要有依据
Absolute Zero: Reinforced Self-play Reasoning with Zero Data
https://papers.nips.cc/paper_files/paper/2025/hash/9837dc00ff67d176373268ed48042d49-Abstract-Conference.html
https://arxiv.org/html/2505.03335v1

AZR利用代码执行环境核验任务和答案。视觉中的“是不是这名穿白衣的人”没有同等可靠的执行器。由此得到的设计要求是：区分可检验的观察关系、教师提供的有噪语义证据与真正的任务正确性；不能把前两者等同于RMOT标签。

4. 双向互学的视觉基础
Deep Mutual Learning
https://arxiv.org/abs/1706.00384
https://arxiv.org/html/1706.00384

该工作用监督损失与同伴概率的KL约束联合训练多个学生。它说明双向互学和固定教师蒸馏是不同机制，但原始监督条件不能原样冒充无目标标签适配条件。我们的监督锚点必须来自已付费的冻结教师反馈。

Dual Student: Breaking the Limits of the Teacher in Semi-supervised Learning
https://arxiv.org/abs/1909.01804
https://arxiv.org/html/1909.01804

该工作研究两个学生及稳定性约束，区别于教师只是学生的EMA副本。借鉴之处是保持两条学习路径及双向作用；限制是预测稳定不等于语义正确，同一物理Track ID也可能串人，不能无条件沿轨迹传播判断。

三、新方向R1：学习进展驱动的挑战者—解决者闭环（优先）

直观解释：一个模型学习“下一眼看哪里、拿哪两张图对照最值得”，另一个模型学习“这次观察怎样帮助找对人”。解决者变强之后，挑战者必须学会换题；挑战者变好之后，解决者应当获得更有价值的新证据。

挑战者A：小型可学习的观察策略模型，不直接输出最终RMOT标签。候选动作是已有任务查询、候选轨迹、真实观察帧和视角组成的查证请求。它不能改写用户任务，不能看到未请求的教师答案，也不能读取人工GT。

解决者S：RMOT指代适配模型，可沿用对象参照与状态建模的输入接口，也必须配套充分训练的普通joint-KD解决者。

冻结教师T：提供外部语义锚点。先研究A和S两个轻量模型的协同进化，不默认同时微调Qwen，不将“固定Qwen指导S”单独称作RSI。

一次闭环：
S的当前预测和已见证据 → A选择新的真实观察 → T提供被请求的回答 → S更新 → 反馈S在哪类题上真正进步 → A更新。

经典思想支撑：主动实验设计、学习进展驱动的课程、带预算的序贯决策。重点是形成新的学习问题与反馈机制，不是在输出端套一个经典校准器。

学习进展的候选度量：
r_t = L_teacher_probe(S_before) - L_teacher_probe(S_after)

这里的probe只能使用预算内单独划出的教师反馈，不是人工GT；按query/track块保留，不能把本次更新直接拟合过的样本当成独立进步证据。预先固定划分、预算、损失和轮数；probe调用也计入总成本。教师风险下降只是课程代理指标，最终是否改善RMOT仍由封存后HOTA和双数量对照回答。

先用三轮，不用更多训练种子；每轮报告新覆盖、实际教师调用、已请求证据风险、保留教师probe风险、预测分布是否坍塌及真实耗时。后续三轮数据与方案全部封存，才统一读取任务GT，避免边看HOTA边挑轮次。

必要对照：
固定挑战者+可学习解决者；可学习挑战者+冻结解决者；均匀/覆盖策略+可学习解决者；双向更新闭环。普通蒸馏获得各自策略完全相同的已请求回答。这样分别判断“选到好问题”和“从相同问题学得更好”，不能把两者混算。

重要输入限制：现有联合证据库不是无限动作空间。若某query在DESIGN与UNIFORM下已覆盖同一候选集合，重排顺序只能研究课程，不能宣称获得更多新证据。先做无标签动作空间与重叠审计；缺失动作只能在被选择时真实请求教师，不能提前读取未来回答或假造答案。

预期与可证伪性：若只在固定题库的顺序上有利、与充分joint-KD打平，则不能声称协同进化提高了语义学习。若挑战者改变了问题难度但不改善保留教师风险或HOTA，应拒绝当前奖励设计；不能只展示更难的题来证明进步。

四、新方向R2：互补视觉学生的双向学习

直观解释：一条学习路径偏重“这个人的稳定外观”，另一条偏重“此刻的状态、运动与场景关系”；双方能纠错，也要防止把共同错误互相强化。

两条路径可以有不同结构偏置，但普通对照必须拿到全部相同的PCD、颜色、几何、上下文和教师回答。不能把更丰富的输入只给我们的模型。

冻结教师意见提供共同锚点，双向作用在明确的证据支持条件下实施。不能仅因一个学生更自信，就认定它一定更正确。对单纯加大模型、两个独立模型的平均集成、单向互教、停止一方更新及真正双向更新分别对照，匹配参数或计算量。

“更稳定、更一致”不是验收结论。需要最终HOTA、正负查询错误分布、两个学生的错误重合、停止互学的消融以及CountMatched。若收益被两个独立模型的平均完全解释，贡献应归为集成，不归为协同学习。

五、新方向R3：有外部证据核验的观察修正闭环

直观解释：模型先给出判断，并指出缺的是局部细节、全局关系还是时序观察；另一模型提出最小追加观察，原模型必须用新证据修正，而不是在原答案上反复自我说服。

可精确核验的是输入与事件关系，例如交换A/B后，A-only/B-only事件必须交换，both/neither不变。这是等变性约束，不是“找对了人”的标签。改变裁剪、时间方向、颜色或遮挡可能改变信息或任务含义，不能随便当成标签不变增强。

这条方向可以与R1组成一个方法：R1负责学会提出有用观察，R3负责约束反馈与修正过程。避免为追求模块数量单独叠一个相同功能的网络。

关键对照：相同追加观察的一次性普通蒸馏；不新增证据的自我修正；相同预算下的随机追加观察；交换或错配反馈的负对照。只有动态闭环在同信息和同成本约束下仍有贡献，才保留对应论文主张。

八、第一段实际RSI闭环与负面对照结果

C1按元数据顺序的首个真实视频dancetrack0004，固定seed0，执行学习挑战者/冻结挑战者两个三轮闭环。每条分支原预算56问，其中6问为分组保留教师probe；三轮累计20/39/56，全部计费。CPU实际86.077秒；0新增教师或主干前向，0人工GT，未生成RMOT预测或HOTA。完整预算分组审计覆盖148设置-视频单元，每个单元都支持三轮新probe、所有query首轮至少一次训练查证；实际epsilon混合策略的score-function恒等式误差1.39e-17。

学习挑战者有3次参数更新，冻结对照0次；两个解决者都有3次更新。但选题集合差异为0，完整提问顺序和最终解决者权重也相同。普通joint-KD和coarse软蒸馏都拿到全部56个已付费回答并充分拟合，KL约3.36e-6和7.51e-7。两个分支教师probe损失逐轮变化完全相同。因此这段实验只证明闭环及对照能执行，不能证明RSI贡献。

教师probe的NEITHER均值分别为0.990948、0.880983、0.991009；它是教师意见，不是目标标签。原始损失下降可能大量来自适应教师No比例。下一步加入只根据已请求训练回答估计的简单类别比例预测器，奖励必须体现解决者超出此平凡预测器的真实进步。不能因这个预测器变差而制造正奖励；冻结解决者时奖励应为0。保留原始奖励作为负面对照，继续同seed0的跨视频前缀累积，而不是换随机种子挑一段正例。尚无RSI任务质量增益。

十、进一步收紧：同一句话、同一视角、不同候选的条件区分

每个教师probe对照固定query和view，保留至少两个不同候选Track ID；它们不保证是真实不同身份，前端可能碎轨，但确实是不同候选。不能用一个query只留一个样本，就声称区分了“查询回答比例”与“对不同候选的判断”。

令Q_i是冻结教师四事件软分布。在每个query/view保留组中，最佳恒定回答为均值Q_bar，其交叉熵为H(Q_bar)。任何归一化预测器的交叉熵L至少为mean H(Q_i)，所以正的条件区分技能
  skill(S)=max(H(Q_bar)-L(S),0)
满足
  0 <= skill(S) <= H(Q_bar)-mean H(Q_i)。
按query等权、query内按view实际样本数加权。新奖励是在完全同一组probe与同一个常量基准下的tanh(skill_after-skill_before)。只学No比例、调整常量概率、冻结解决者都不能获得正奖励；只有在教师反馈上形成非恒定的条件预测优势，才可能得分。右侧的信息差小，证据就弱，不能将微小浮动当大进步。建议固定SGD更新actor，避免Adam把极小奖励归一化成大参数步长；正式参数须在新质量实验前固定。

这是经典proper scoring、Gibbs不等式和条件化思想在学习目标中的应用，不是把一个经典算法接到RMOT输出上。这里的最佳常量由已付费教师probe拟合，仅用于反馈诊断，不是人工GT oracle，也不送进本轮学生训练或最终解码。数学结论仅关于教师评分规则，教师可能有系统错误，真实RMOT贡献仍要靠全部六设置及双向CountMatched。

配对预算审计覆盖全部148个设置-视频单元，0真实教师答案读取、0模型训练、0GT。C2/C3/C4/C5每个视频均可提供三轮配对；C1和C6各21/25可提供三轮，其余因预算或有限题库缺少足够同视角多轨迹对照。所有query仍保留首轮训练，预算不增加，任何视频/预测不删除；缺少有效probe的轮次不能制造反馈。源码rsi_discrimination_feedback.py与聚合审计rsi_discrimination_feedback_audit.json。

当前状态：配对预留和条件评分函数及数学/预算检查已实现；尚未接入完整RSI训练，也没有新RMOT质量结果。下一步优先把该反馈与固定SGD接入可续跑闭环，保留同probe的RAW/FROZEN对照，再实现并执行完整六设置。此前21配方/582官方评价的四卡实验继续，不修改其运行数值源。

十一、训练信号还需对齐“选对哪个候选”：新的跨候选比较假设

检查当前联合教师采集源码可以确认：每个case只有一个track_id，A/B是同一候选的两个时刻。因此条件化的A-only/B-only主要监督“这个候选何时符合”，没有直接提供“两个不同候选谁更符合”的比较。此前实验尚未给出新HOTA，不能据此宣布它是失败根因；但这是必须区分的学习任务。

下一项实际教师pilot应当在同一query和同一请求时刻，展示不同候选A/B，仍允许A-only、B-only、both、neither，不强迫唯一获胜。冻结Qwen真实前向；AB/BA顺序对照、同视觉上下文的独立二元回答、CROP强基线全部保留。选例只用元数据和冻结学生，不用GT。旧“同一人两个时刻”的缓存不能当成新“两个候选”的联合回答。

经典思想是条件比较学习：若两个候选效用为b_q+f_i和b_q+f_j，条件在恰好一个匹配时，相对概率只依赖f_i-f_j，公共回答偏置b_q被消掉。这样学习直接指向候选区分；它与“同一轨迹的状态差异”是不同归因。实际网络必须允许两候选各自的对象参照输入，并保留计数/不存在性通道；一般joint-KD也必须拿到全部相同的两个对象、上下文和联合目标，充分拟合。

必须保留候选自身的稳定身份证据h_i。要消掉的是各候选共同的query回答偏置b_q，不是候选特有的语义证据。若u_i=h_i(C_i)+g(C_i,x_i)-mean_anchor g(C_i,a)，条件比较必须包含h_i-h_j；仅对同一轨迹做中心化状态差异，会把稳定身份项取消掉。这是下一版结构需要明确的区别，尚不是已有实验给出的因果结论。

与RSI的组合方式是：挑战者学习挑选有价值的候选比较，解决者学习候选效用，解决者的条件区分进展再反馈给挑战者。人类视觉方式提供“对照候选”的问题结构，经典条件化提供消除公共偏置的理论依据，RSI提供学习过程双方的闭环。这是待验证候选，不是已经证明的三个创新。

在大规模采集前，先核对RMOT任务/查询的时间语义，防止把描述某个持续指代对象的语言，误改成每帧独立属性分类；这个核对读取任务约定和解析代码，不能读取尚未封存研究的人工GT。随后用小型真实GPU教师pilot验证跨候选反馈的信息量与格式，再固定模型、对照和预算，进入六设置实证。当前跨候选teacher pilot及其新模型入口尚未实现/启动。


十二、新增视觉RSI文献及三条可检验路线（本轮追加）

用户指定文章讨论自动化研发的反馈循环。我们另行核对了以下原始论文及方法部分，区分研究启发和本项目的实验结论：

A. Self-Evolving Visual Questioner（2026-06）
https://arxiv.org/html/2606.13929v1
模型迭代提出视觉问题，初始模型参与改写，筛选具有视觉依据且更有挑战的问答，再混合出题与回答格式训练。对我们的启发是“学习如何观察/提问”应有独立机制和质量检查，不能仅用求解器的熵当作问题价值。它的问答有效性仍含模型判断，不等于RMOT人工真值。

B. Paying More Attention to Visual Tokens in Self-Evolving Large Multimodal Models / VISE（2026-06）
https://arxiv.org/html/2606.27373v1
该文指出，答案越来越一致并不能确保视觉依据越来越充分；它结合已知几何变换的定位一致性及局部视觉证据受扰后的反应来构造奖励。对我们的启发是给闭环加入“是否依赖了图像”这一检验。RMOT中模糊一个目标不证明整个视频没有此目标；左右位置和动作查询也未必在任意增强下保持答案。因此不能无条件把增强样本当正例、把遮挡样本当No。

C. VICO: Visual Environments Co-Evolving for Vision-Language Model Reasoning（2026-10）
https://arxiv.org/html/2610.10782v1
Actor与可学习的环境改写器共同调整任务难度。其可验证性来自场景图、图表底层数据或受保护答案区域；原文使用带这些结构的种子样本。我们没有对应的目标域人工结构标签，不能原样搬来宣称无标签。可借鉴“观察环境也随学习者演化”的思路，用真实候选和有效裁剪构造课程，所有语义有效性仍由冻结教师查证。

D. MM-Zero（2026-03）
https://arxiv.org/abs/2603.09206
引入出题、代码绘制视觉内容、求解三种角色，并利用执行反馈与视觉核查构造学习任务。它提示反馈循环可以包含观察生成环节，但可执行合成场景不等同于真实体育/舞蹈/驾驶视频。暂作为后续理论参考，不据此新增大规模渲染队列。

这几篇论文与R-Zero共同形成三条备选路线；最终以同条件RMOT实测决定哪些成为贡献，不能预先宣布三个创新已成立：

路线1（优先，已有初步实现）：挑战者学会找“有学习价值的候选对”，RMOT解决者保留对象外观差异并学习条件判别；解决者在新教师probe上的条件区分进展再反馈给挑战者。已完成的RAW与PRIOR三视频实验仅显示部分提问路径发生改变，未证明HOTA；常量No奖励是必须排除的反例。

路线2（备选）：外观学生与空间/短时运动学生互为挑战者，挑出各自有依据的分歧。教师负责仲裁；互学前后、冻结一方、单向蒸馏须匹配证据和训练量。分歧本身不是“谁正确”的标签，一致也不是共同进步。当前尚未训练此双学生方案。

路线3（新增备选）：学习观察方式，结合视觉依赖检验。控制器选择在真实图像中看哪里、看多长的历史，学习者对经过教师验证的观察更新；已知几何关系只提供可验证的辅助约束。语义会改变的变换不得强行当不变性监督。需要固定观察器、固定学习者、教师蒸馏与随机/常量奖励对照。当前只做文献与方案登记，尚未启动此独立质量实验。
