二、V1 暴露出的三个精确失败原因（全部来自收据与 DetA50/AssA50 分解）
======================================================================

1. KITTI（C2/C5）严重欠拟合：
   - 固定 1100 步 + 偏重 weight_decay=0.02 在 10–17 查询的 Dance/Sports 上收敛（proper excess CE 0.005–0.014），但在 215 查询/视频的 KITTI 上严重欠拟合（C2: S_id=0.088 / S_dyn=0.061 / REG=0.041；C5: 0.062 / 0.045 / 0.028），导致 C2/C5 落后于原 6k 充分训练的 PARENT_POOLED。

2. 逐帧残差抖动破坏 AssA50（全六设置 AssA50 掉 0.6–3.3 分）及 P@O 排序：
   - V1 对静态查询（is_dyn=False）也叠加了无界逐帧动态残差 gam_s * f_dyn_res（0.12–0.29），在 SportsMOT 上更叠加了方差较大的帧级残差，导致同帧 top-K 选框在相邻帧来回跳变，AssA50 相对 REG_SOFT_POOLED 全六设置下跌（C1 -0.66、C2 -3.34、C3 -1.12、C4 -1.12、C5 -2.52、C6 -0.61），进而压低了 P@O（主@对手数量）。

3. 强制 k_nn=5 全连接图在稀疏正类（KITTI）上过平滑正例：
   - KITTI 一条精细查询往往只匹配 1–2 辆车（其余 25+ 辆为负），强制连 5 个近邻在 lam_vis≈1.8–2.0 下把孤立正例拉向负例均值，导致 C2 少召回约 2.7 万 TP。

尚未排除原因：
- 全部数据仍属 DEV；本阶段仍在固定 UNIFORM 问答上打磨双层转导与双学生协同学习内核，尚未回接主动观察（I3）及测量 fresh 端到端冷启动成本。

三、V2（DUAL_TRANSDUCT_COEVOL_V2）精准修正设计
======================================================================

1. 人类视觉与经典思想：
   - 借鉴 SCAP（CVPR 2025 支持团）与 DualTemporalMOT（NeurIPS 慢身份零抖动）及变点分段思想：
     * 静态属性（颜色/衣着/身份）在同一视觉连续片段内不随帧随机抖动；
     * 视觉相似性传播仅发生在“真正相似的支持团（similarity-gated tight clique）”内，不强行把孤立特异目标拉向不相似的多数背景。

2. 三项具体改动（100% 无 GT、全六设置统一规则，不修改 V1 已登记源码）：
   - 改动 1（自适应充分收敛门限）：将 weight_decay 调至 3e-3、dropout 0.15、lr 5e-4；Round 0 与同正则普通对手 REG_SOFT_KD / REG_HARD_KD 均按统一 proper excess CE <= 0.01（上限 3000 步）收敛，根治 KITTI 欠拟合且保证普通对手同样充分。
   - 改动 2（零抖动静态轨迹 + 概率域轨迹汇聚 + 强平滑有界动态段残差）：
     * 轨迹汇聚统一改用精确概率均值 logit（与 PARENT_POOLED 同尺度，不受单帧极端 logit 离群值扭曲）；
     * 静态查询（is_dyn=False）强制 gamma_dyn_static = 0（零逐帧抖动，完整守住 AssA50）；
     * 动态查询（is_dyn=True）提高时间平滑系数（base_decay=0.94, kappa=6.0）且将 gamma_dyn_dyn 约束在 [0, 0.35] 内由 OOF-LOTO 择优，仅在真实动作/方位段变化处生效。
   - 改动 3（相似度门控支持团拉普拉斯 k_nn=3）：
     * 将图近邻收紧至 k_nn=3 并增加距离相似度门控（仅连接归一化距离 <= 1.25 的真正相似邻居），同时将单孤立正例与不相似多数背景解耦，保留 SportsMOT/Dance 同队同衣传播红利，消除 KITTI 稀疏正例过平滑。

3. 固定公平对照与验收标准：
   - 沿用完全一致的 7 个公平对手（原 6k PARENT_SOFT_KD / PARENT_POOLED + 同自适应收敛 REG_SOFT_KD / REG_HARD_KD / REG_SOFT_POOLED + 特权同读出 PARENT_SHARED_TRANSDUCT / REG_SHARED_TRANSDUCT）。
   - 全 148 单元、2960 新输出封存（GT=0）后，经 20 核无损官方 TrackEval 产出 132 HOTA / 126 效应并独立公共复算（误差 < 1e-8）。要求在全部六设置相对所有普通充分对手原始与双向 CountMatched 均正向提升，再推进 I3 主动观察回接、模块/交互消融与 fresh 端到端成本。
