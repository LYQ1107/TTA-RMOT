TTA-RMOT：从经典思想推导对象—关系机制，而不是套经典算法调分
2026-11-22；持续研究记录；科研 Goal ACTIVE

一、用户设定与本轮纠正

任务始终是跨域 RMOT：沿用官方固定候选框和 Track ID，只用目标图片、语言查询与冻结教师进行适配。人工目标标签只在本项研究的全部原始预测、数量对照封存后，由隔离评估进程使用。官方前端的训练来源另有局限，不能声称整个检测器从未见过目标域训练标签。

同一个框架以三个候选创新点组织，在六个跨域实验设置检验。六个设置不是六个独立方法，也不能在每个设置用 GT 选一套公式。

用户明确要求“学习经典算法的思想，为论文提供理论支撑”。因此 DS、PAVA、图传播、EMA 等算法名本身不是我们的创新。正确研究链条是：发现任务矛盾 → 提出可检验的结构假设 → 由经典思想推导适合这个矛盾的机制 → 证明机制在假设下的性质 → 在公平实验中检验实际贡献。

不得把经典定理改名成新理论，也不得把代理损失下降写成 HOTA 必涨。现有数据全为开发数据，所有多轮开发后的区间都是描述性证据，不是独立盲测。

二、三个候选创新如何组成同一条视觉推理链

候选 I1：为解决疑点而安排观察。
人类视觉动机：并非一直盯着初始最像的人；需要扫视尚未覆盖的候选，并选择真正能区分两种解释的观察状态。
经典思想来源：主动感知与实验设计。Bajcsy 的主动感知强调目标和当前解释控制观察过程；这不等于“调用更多视角”。
我们的任务问题：问过很多次，不等于覆盖了正确候选；看到同一位置的重复答案，也不等于能辨识“位置变化如何影响关系判断”。
拟设计内容：把候选覆盖和状态差异的信息量放进同一个有限预算观察目标，而非只按学生高分排序。若采用覆盖项加 log-det 信息项，必须在冻结候选特征、固定代价和固定参照观测等条件下讨论次模性；1-1/e 只约束该代理目标，不约束 HOTA 或真实墙钟最优性。
状态：已补充覆盖—辨识激励的计划器原型、数学性质检查及真实输入构造检查；尚未用它采集新回答或评价策略质量。现有固定旧问答研究没有验证这个新选题点。此前 COVER/SEARCH 的负结果保留，不能靠给旧选题换名字宣布贡献成立。

候选 I2：区分对象本身、观察通道与变化的关系证据。
人类视觉动机：同一辆车不会因为从画面左边开到右边就变成另一辆车，但“在左侧”这一判断可能改变；教师也可能有稳定的对象偏好或视角偏好。
经典思想来源：消去干扰变量、组内对比、可辨识性与稳健估计。核心不是照搬一个评分器，而是明确哪一项应当消去、哪一项应当保留。
本轮已实现内容：在同 query、同给定 Track ID、同 view、同 video 的教师回答中做组内中心化，用视觉状态变化解释回答差异，再作非负、带 Huber 损失的凸标量估计。单个对象/通道组的总权重归一为 1，完全相同请求与回答的重复不增加权重。
状态：数学单元检查、真实数据路径检查及 teacher-only 前缀拟合通过；尚没有本项质量评价结果，不能把它叫作已经有效的创新。

候选 I3：保持对象身份，更新当前关系，并约束描述间的一致性。
人类视觉动机：“记住这个对象”与“记住它永远在左边”是两件事。对关系的更新必须对应当前画面；不同描述也应有兼容的理解。
经典思想来源：状态分解、关系迁移与约束优化。正确性依赖对象关联和语言关系假设，不能无条件传播判断。
本轮已实现内容：把 I2 学到的关系变化迁移到当前候选框位置，稳定对象分量由已封存的粗粒度模型提供。未支持的查询完全回退到原模型；不强行用位置解释动作、朝向、队伍名或参照对象关系。
现有查询逻辑投影仍作为机制证据保留，但其语言蕴含假设不是标注真值；也不把投影算法本身当创新。
状态：新的逐观测关系场及其均值、置乱、参照点消融已实现并登记；还需官评、CountMatched、模块交互及真实成本支持。

三个点应共同回答：该看什么 → 从观察中能辨识什么 → 如何把辨识结果用于当前对象和关系。现在只是逐步实现这一链条，未完成整套新框架。

三、为什么需要对象—关系分解：新的任务证据

此前仅看 Dance/SportsMOT，稳定片段最终输出翻转为零，不能据此证明所有关系都应该恒定。

KITTI 的封存后诊断显示：在可匹配的同一个真实对象内部，部分查询的标注成员关系随帧变化。空间类 361 条查询中，即便限定同一真实 GT ID，最优的“整条轨迹永远输出同一判断”仍有 24,536 个观测行无法同时判对，占这部分匹配查询观测的 2.9253%。

这个数是条件分类表示误差下界，不是 HOTA 上界，也不是 18.9% 真实目标必然漏检。GT 仅用来暴露当前表示的问题；新适配代码不读取这些 GT ID 或错误标签，使用的是给定 Track ID。

还核实了一个重要事实：历史 CROP 提示词已经提供归一化位置。因此不能把问题解释成“教师根本没拿到位置”。新的问题是：旧系统把不同帧的回答压成同一个轨迹分数，可能丢掉了有效的关系变化。

同对象、同视角的旧实际问答也包含位置变化：C2 有 1,275 个有变化的组，C5 有 1,269 个。这个 teacher-only 事实只说明存在可用于拟合的变化，不证明教师答案正确，也不证明几何变化具有因果语义效应。

四、已实现标量原型的明确模型

保守文本规则只接受绝对画面左/右关系。定义 z 为“越大越符合查询”的水平位置：右为 x，左为 1-x；x 是框中心除以图像宽度。

分组 g = (video, query, provided TrackID, view)。对实际请求 e，教师回答概率 p_e 先裁剪到 [.02,.98]，记 l_e = logit(p_e)。一个用于推导的局部模型是：

  l_ge = a_g + beta_* z_ge + epsilon_ge。

a_g 收集该对象/查询/视角在本视频内稳定的分量。它不是人工身份标签，也不保证纯粹代表“对象语义”。beta_* 是共享关系斜率。该模型可能不成立：Track ID 会串人，教师有非加性错误，语言的“左”可能是对象参照系，关系也可能并非单调。

代码不声称这个模型描述了所有查询，只把它作为一个局部候选机制的可证伪假设。

五、可以严格说明的性质及其边界

性质 1：固定权重下，组内中心化消去固定的加性干扰。
令 a_ge >= 0 且每组和为 1，x_ge = z_ge - sum_e a_ge z_ge，y_ge = l_ge - sum_e a_ge l_ge。若同组所有 l_ge 加同一个常数 c_g，则 y_ge 完全不变，拟合输入因而不变。
这是加权中心化的代数性质。它要求中心化时的权重固定；若改变原始概率导致置信度权重或 logit 裁剪发生变化，就不能据此宣称完整教师流水线对任意偏置都不变。

性质 2：有正则不等于关系可辨识。
若所有同组 z_ge 相同，则该组所有 x_ge 为零，无法提供任何斜率信息。正则化可以产生唯一数值解，却不能凭空产生辨识信息。代码记录 excited_groups 和加权中心 Gram，不把优化成功当作学会语义。

性质 3：实际标量目标是强凸的，有唯一解。

  minimize over beta >= 0:
  J(beta) = mu*beta^2/2 + sum_g sum_e a_ge Huber_delta(beta*x_ge-y_ge)。

本轮固定 mu=.01，delta=1。Huber 损失凸，二次项使 J 至少 mu-强凸，闭凸约束 beta>=0 下解唯一。
导数为 mu*beta + sum a_ge clip(beta*x_ge-y_ge,-delta,delta)*x_ge。
若 J'(0)>=0，约束最优解为 0；否则单调导数的唯一正根给出解。代码用括区间加一维求根，记录 KKT 残差，并与独立有界标量最小化进行了对比。
唯一解是优化性质，不是跨域语义正确性。

性质 4：组贡献有界，但粗略稳定性界并不紧。
因为 z 位于 [0,1]，中心化后 |x|<=1；Huber 导数绝对值不超过 delta，每组总权重为 1，所以单组对数据项梯度的贡献绝对值不超过 delta。固定其它组并替换一组时，两组贡献差至多 2*delta；强凸性可导出解的变化不超过 2*delta/mu。
当前常数下该界较松，不能包装成已获得优秀统计泛化。它只说明重复帧不会通过无界累加单组权重无限支配拟合。

性质 5：完全相同请求和回答的重复不增加证据量。
代码对完全相同请求内的不同概率值去重，再取中位数。重复已有同一输入/同一回答不会改变这一集合，因而不会改变输入和拟合。新增不同回答会改变集合；不同时间、不同裁剪也不是同一观测。不能把这个性质夸成“所有相关视角都已去相关”。

性质 6：迁移修正的赔率变化有明确上界。
对已有粗粒度概率 u_qt，参照位置 r_qt，当前位置 z_qtf：

  d_qtf = clip(beta_hat*(z_qtf-r_qt), -ln(3), ln(3))；
  p_qtf = sigmoid(logit(u_qt)+d_qtf)。

在原概率未触发数值裁剪的条件下，修正后的赔率至多乘 3、至少除以 3。更一般的概率改变量至多 tanh(ln(3)/4)，约 0.268。它约束修改幅度，不证明修改方向正确。
beta=0 或文本不支持时，代码保留原概率逐元素精确回退。图像和框坐标同比例缩放时，归一化位置不变。

性质 7：可说明条件重建，不能无条件证明 HOTA 上升。
若关系模型确实正确，u 确实代表参照状态的正确概率，beta_hat=beta_*，且修正上界不截断真变化，那么上式重建该模型的当前状态概率。
实际 u 是蒸馏和已有结构模块的输出，不保证等于参照状态真概率；概率平均也不等于参照位置处的 logit。因此这一命题是理想条件说明，不是给当前代码颁发正确性证书。
logit 误差可分为参照误差、斜率误差乘状态距离以及修正截断误差。任何一项过大都可能伤害最终结果。HOTA 还含检测数量、框匹配及身份关联，不能从这个局部重建命题推出 HOTA 改善。

登记文件：docs/a100_six_direction_20261122/relation_transport_registration_v1.json。

  RGB_RELATION：同一关系迁移加普通 RGB，用来检验条件组合与交互；
  UNCENTERED_RELATION：参照一律 .5，检验对象观测参照是否有价值。

其残差接在过去/当前视频已发出的普通 RAW_RGB_FINAL 上，不能加载未来视频训练完的头。采用相同充分训练规范，最终检查点，最少 4000、最多 16000 步及教师 KL<=.005 规则；未达容差必须如实报告，不得说成已经充分贴合教师。

全组额外 444 个普通逐帧头拟合；主机制只新增标量关系估计。允许普通对手更复杂，避免靠欠拟合对手胜出。

原始输出 162 份，逐查询逐帧的双向数量对照 288 份，共 450 份全部封存后才做本项人工 GT 官评。数量匹配按真实逐观测分数排名，不错误复用旧恒定轨迹排名；CountSelf 必须逐文件复现。

结果解释：
  完整关系优于粗模型，但不优于轨迹均值：可能主要改变数量/基率，不能归功于时间关系。
  完整关系优于置乱，却不优于粗模型：置乱只是有害，不能说新机制有净收益。
  普通逐帧蒸馏持平或更好：相同信息下没有证明本机制优越，必须保留负结果。
  完整关系在原始与数量匹配后都优于强普通对手，并优于均值/置乱：才较有力支持状态对应贡献。
  C2/C5 以外原型回退：即使那四设置涨分，也不能算这个新关系模块的贡献。
  两模块单独涨点不能相加：报告四项 HOTA 交互点值及相同底座条件效应。

这批是固定付费证据的质量回放，不是端到端成本。若配方保留，再执行匹配的新真实采集/冷启动成本，不能拼接旧时间与新精度。仅用物理 GPU0/1/2/3，在当前 RGB 阶段释放后由控制器预检分配，保留有效视频检查点。

八、现有六设置结论与完成边界

旧三种子统一迁移配方对最强已观测普通基线，六设置差值为 +5.5766、-.5241、+.5490、+.4761、-.5951、+.8828 HOTA。查询一致性配方在统一独立解码下相应为 +2.2268、-.5170、+.7883、+.8585、-.4584、+.5827。两表解码条件不同，不横向偷换，也不拿更高的事后控制改主方法。

这说明“把旧模块组合起来就能在六设置大幅、可靠获胜”的目标没有完成，尤其 KITTI 仍失败。个别正值也可能区间跨零或主要来自数量变化。

新关系原型是由具体失败推导出来的候选，不是证明目标已经完成的新措辞。I1 有计划器原型但新证据实验尚未完成；I2/I3 原型质量尚待本项评估；全框架仍需六设置、清晰模块贡献、强普通蒸馏对手和真实部署成本。科研 Goal 继续 ACTIVE。

十、追加：由关系可辨识性反推主动观察设计

新源码：flex_uda/active/observation_design.py。
真实输入复核：scripts/a100_observation_design_probe.py。
这是计划器原型，还没有接入新的教师采集或报告 HOTA。

关系斜率若需要同对象的状态变化才能辨识，就不能只追求“问了多少个框”。但反复观察同一对象又会损失目标覆盖。因此先支付一部分预算观察不同对象的参照状态，再冻结这些已支付参照，在“看一个新对象”和“看已有对象的不同状态”之间分配剩余预算。

第一阶段固定用 ceil(.75*K) 个名额（不超过对象数），对非负的视觉相似度做加权 facility coverage 贪心。先验只打破同收益平局，不把低先验对象直接剪掉。这个阶段没有用教师答案或目标标签。

第二阶段的动作集合在第一阶段后冻结：未覆盖对象的参照帧，或者已支付参照对象的其它实际采样帧。每个动作是一条新请求，不能假装参照回答免费。固定相同视角才能使用组内干扰消去的假设。

记 C(S) 为已有参照加所选动作对全部候选的加权覆盖；
V(S)=sum_t max_{a in S on object t} ((z_a-z_anchor)/2)^2。
同一对象共享参照的多个差分不独立，所以只取该对象最大激励，不逐条累加它们的信息量。没有位置关系门控的查询，激励为零，仍由覆盖目标分配预算。

固定 eta=.25、lambda=.01，第二阶段目标是：
  F(S)=(1-eta)*C(S)+eta*log(1+V(S)/lambda)/Z。
Z 是按固定预算确定的正归一化常数。F 是几何辨识激励代理，不是实际教师的 Fisher 信息、贝叶斯信息增益或正确答案概率。

条件性质的推导：
1. 对固定非负相似度，增加一次观察对“逐候选最大相似度”的边际收益随已选集合增加而减小，因此 C 单调次模。
2. 对每个对象取最大非负激励也有同样性质，求和得到单调次模的 V。
3. log(1+x/lambda) 非减且凹。更大的基值、更小的 V 边际增量都会减小 log 边际，故复合后仍有收益递减。
4. 非负加权和保持这一性质。在冻结参照、冻结动作、等单位成本、固定基数预算下，标准贪心对本阶段 F(S)-F(empty) 有 1-1/e 近似界。

这个界不适用于任意动态重设参照或设计向量；不是两个阶段联合最优的证明；不适用于实际推理时延可变的墙钟成本；更不是 HOTA 近似保证。阶段比例 .75 和权重 .25 是未用目标标签选择的固定研究配方，尚无最优性结论。

三个性质与数据约束检查通过：穷举小集合核对单调及次模边际、共享参照的较弱重复对比不增加代理信息、所有对比必须有已支付参照且请求唯一；另检查无关系信号时优先覆盖新对象。真实 C1/C2/C4 输入只构造计划，不请求教师：示例分别分配 5、23、4 次请求；C2 示例 18 个对象参照加 5 次状态对比，其它两例均把预算用于不同对象。

同预算下，三个示例的历史实际问答分别涉及 5、21、1 个不同 Track ID，新计划分别涉及 5、18、4 个。C2 明确牺牲部分对象覆盖换状态激励，不应把新计划说成所有情况下都覆盖更多。相似特征的代理覆盖也不等于覆盖真实目标；源域特征误导时计划仍会失败，必须用正式结果检验。

这些只是原型可执行性与代理数学性质。下一步若执行，必须同时比较相同实际预算下的普通先验/均匀/纯覆盖策略，并把本策略取得的相同回答交给充分普通蒸馏；不能把“问得更好”和“融合得更好”混成一个贡献，也不能把未请求的历史回答塞进新适配。

十一、从计划器推进到真实新问答

六设置 148 个视频的四种策略请求清单已全部生成。每个视频的实际旧问答数只用来固定总预算；四策略使用相同的新均衡查询配额、原始三采样点、最大面积参照帧和共同视角规则。旧回答概率、旧信念和 GT 没有参与选题。
每策略总调用 55,019，各设置依次为 3,047、20,955、3,508、3,508、20,955、3,046。所有查询均有非零配额。这里的覆盖指输入 Track ID，不是正确目标覆盖。
C2 设计保留 19,477 个不同 query-track 单元，另用 1,478 次请求观察状态变化；C5 为 19,536 加 1,419。其它四设置没有适用的位置关系，设计与纯覆盖相同。先验和均匀对照先访问不同对象，不刻意削弱它们。

随后在三个首视频、四个按文本选定的查询上，采集了四策略请求的共享并集：59 个真实 Qwen3-VL-2B 前向，0 缓存命中。三种视角 CROP/CLIP/FRAME_BOX 均有实际输入，CLIP 未回退。教师参数 SHA 与已实测 C2 流完全相同，优化器更新 0，目标 GT 读取 0。
四策略各自对应 29 个逻辑请求；共享采集只做并集 59 个物理请求，不能把这一次并集运行时间冒称四策略各自部署时间。

该数据准备的实际 worker 墙钟 507.047 秒：GPU上下文/临时占用 .489 秒，清单读取 16.303 秒，教师加载与初始核验 444.669 秒，真实服务含图像 I/O 31.630 秒，最终冻结核验 13.872 秒。服务内部真正模型前向共 3.237 秒，是嵌套时间，不能再加一次。
学生特征已经预付、其它卡还在跑质量任务，NAS/OS 缓存未清理。因而这不是旧“600秒含全部启动”的成功对照，也不是方法精度或端到端成本结论。原始 QA 留在本地，Git 只保存聚合收据。

十二、新输入审计：先验证观测是否保留了问题所需信息

来自经典可观测性/测量充分性的设计思想：若两个状态经过观测构造后完全相同，但任务答案不同，则任何只看这一观测的判断器，都不可能对这两个状态同时正确。这是简单的必要条件，不是新的 RMOT 性能定理。

对当前 CLIP 构造，考虑框和其局部图像一起作整数像素平移，并保证裁剪及边距都在图像内部。每帧裁剪像素和其顺序可以保持完全相同；CLIP 提示词也不变。但对象从画面左侧移到右侧时，“位于画面左侧”的谓词可以改变。因此，把局部裁剪用于这种绝对位置谓词，存在观测等价、答案不同的反例。
此反例不能直接套到 CROP：实际 CROP 提示已经带有归一化中心坐标。FRAME_BOX 的整图也可能保留位置。背景纹理还能间接提供线索，所以不能宣称所有实际 CLIP 输入都无法判断位置。

六设置实际旧输入审计：
  C2 有 1,797 条 CLIP 请求，C5 有 1,595 条，均未在提示中提供全局坐标。所有这些 CLIP 都含至少两个不同帧，故“只是重复同一张图”的猜测在这些记录中不成立。
  KITTI 共 286 条含运动关键词的查询，其中 84 条也含空间词；保守的 on/at-left/right 明确位置表面形式有 46 条。这个语言规则不是对标注语义的认证。
  旧 C2 仅 9 条、C5 仅 4 条此类明确位置+运动查询只拿到 CLIP，其余也有 CROP/FRAME_BOX。因此这只能解释部分潜在问题，不能当作整个 KITTI 失败的主要原因。
  另外四设置的查询没有命中运动词，不把这一机制包装成它们的贡献。

重要的新设计检查：新清单当前沿用公共 route，MOTION 一律给 CLIP。若直接进行全面采集，会让上述复合查询失去旧混合视角中的位置提示。故先保留已完成的真实小测试作为旧接口控制，暂不把这套固定旧路由直接当最终新观察接口。

已实现独立候选输入模块 flex_uda/active/state_teacher_inputs.py，不修改正在运行的教师或质量帮助函数。它保留完全相同的裁剪图像和冻结权重，提供五个明确控制：
  ORIGINAL：原始 CLIP；
  LAST：明确最后一帧为当前判断时刻，前面只作上下文；
  POSITION：LAST 加每帧在原整图中的归一化框中心/大小；
  TIME：LAST 加真实源帧相对最后一帧的偏移，不假设帧率；
  STATE：两种元数据都保留。
CROP、FRAME_BOX 及 CLIP 回退保持原始输入。信息来自给定候选及已有图像，不引入人工标签、额外图像或网络更新。

三个输入层检查已通过：保留真实时间间隔与重复观测；仅位置/仅时间控制分别打破对应的观测等价；原始图像及非 CLIP 控制逐项保持。尚未用新提示进行 GPU 质量比较，更没有证明教师回答变准。
后续同图像、同问题、同冻结教师的配对测试必须保留所有五个控制；若正式适配采用 STATE，普通蒸馏也必须得到同样的 STATE 回答。不能把新增信息只给主方法，再把涨分说成融合优越。更多输入信息也可能让有限教师分心，必须实测。

实际准备进展：首个 KITTI 视频按文本固定了两条明确位置+运动查询及一条其它运动查询，各取四个真实 CLIP 请求，共十二问题、六十个提示控制。五控制的像素 SHA 完全一致，提示键不同，最后帧均为当前帧，全部12请求满足预定输入条件。该小测试只选择真正有时间上下文的 CLIP 输入，不是完整 RMOT 评测的样本筛选。

真实配对测试也已完成：GPU1新60前向、0缓存，五控制全部使用相同像素及400个视觉token，教师权重仍为同一9a13380...，所有60答复top1均为Yes/No，GT0、适配0。worker514.940秒，其中teacherload487.104秒，真实服务含IO11.764秒，内部GPUforward4.799秒，最终seal14.030秒。后几个控制共享暖图像/模型缓存且顺序固定，不能用它们服务更快来声称新增信息提高效率。

更重要的是不能把回答变化包装成信息收益：
  LAST相对ORIGINAL已经改变5/12个二元答复；
  POSITION、TIME、STATE分别相对LAST仅多改变1/12；
  STATE相对POSITION或TIME没有额外二元变化。
这些变化全部为Yes转No。明确位置+运动子集8问题中，LAST改变4个，元数据再改变1个；其它运动4问题中，LAST改变1个，元数据没有额外二元变化。
因此大部分已观察变化来自判断时刻/措辞控制，不能直接归功于新增几何或时间数据。我们不知道这些No是否正确，也没有因此把LAST等事后更高控制升为主方法。元数据的独立贡献仍需长度/格式匹配的安慰剂或任务兼容反事实来区分；不据此立即进行整套新提示的昂贵采集。

十三、为什么还要检查“改得动什么”，而不能只证明优化可解

当前关系原型将 logit 改变量限制在 ln(3)。因此原概率严格小于 .25 或大于 .75 时，任何允许修正都不能翻转 >.5 的输出决策。这是表示能力限制，不是程序错误。

封存 R3 粗粒度输出的无标签审计显示：在保守支持的左右查询上，C2 三种子的观测受限比例为 31.08%、32.83%、34.04%；C5 为 26.52%、27.62%、28.31%。它没有锁死“大多数”观测。并且高置信度可能本来正确，不能把这些数叫作误差率。
更贴近动态证据的单元是教师同对象、同视角在不同帧给过两种二元答案的 query-track：C2 共322个，其中32/33/41受限；C5共438个，其中78/74/84受限。三个种子复用同一教师事件，不能当三次独立重复。

这个结果支持保留原450对照继续检验，不支持立刻凭GT把cap调大。它也明确了下一种候选机制的方向：如果观察到稳定成分与关系效应混在一个过于自信的复合分数中，可考虑先用组内差分学关系，再利用已知关系偏移重新拟合稳定对象成分，最后重建当前状态判断。这是部分线性/干扰分离思想；它与“把已有复合分数小幅校准一下”不同。
新的稳定成分模型尚未实现，是否需要它应由完整实证决定。若执行，必须另行固定方法，保留旧有界原型，以及同单帧证据、充分训练的普通逐帧蒸馏对手；不能通过给普通对手塞入不相容的 CLIP 标签来制造优势。
