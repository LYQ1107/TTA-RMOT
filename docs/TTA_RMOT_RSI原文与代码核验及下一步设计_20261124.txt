二、这些文献真正值得借鉴什么

1. Self-Improvements in Modern Agentic Systems: A Survey
版本：2607.13104v1，2026-07-14。
原文：https://arxiv.org/html/2607.13104v1
官方汇总：https://github.com/selfimproving-agent/Awesome-Self-Improving-Agents

它区分模型参数的持续更新、执行框架的持续更新和临时工作记忆。对我们有用的是：明确谁更新、反馈从哪里来，分离模型学习与工具/路由变化，并检查评价器是否被过度优化。综述提供组织与验证框架，本身没有证明某个RMOT模块有效。

2. TTRL: Test-Time Reinforcement Learning
当前核对版本：2504.16084v3，2025-06-30；不是只读最初v1。
原文：https://arxiv.org/html/2504.16084v3
代码：https://github.com/PRIME-RL/TTRL
核对：verl/verl/trainer/ppo/ttrl_utils.py中的apply_ttrl_gt、_majority_vote，以及ttrl_math答案评分。

可借鉴的是用当前模型产生经验、构造在线更新信号，再让更新后的模型继续产生经验。它用多次采样的多数答案构造伪标签；这不等于多数答案是真值。数值推理里，不同错误答案之间仍可能产生正确负奖励，其多答案结构不能直接套给我们的Yes/No候选判断。

本项目的一个简单推导：若候选标签y和多数伪标签y_hat都只有0/1，且y_hat不等于y，那么对任何二元输出z，都有1[z=y_hat]=1-1[z=y]。也就是伪标签一旦错，该候选所有二元奖励都反向。这不是TTRL论文的RMOT实验结论，而是二分类奖励定义的直接性质。因此不能靠复制多次No来训练一个越来越相信“全都没有”的系统；也不为多数投票追加神经训练种子。

代码还保留original_gt及其评价指标。字段用于什么必须沿调用链判断，不能看见名字就指控训练泄漏；我们也不会把这套带基准GT诊断的流程直接复制进目标无标签适配过程。

3. Agent0: Unleashing Self-Evolving Agents from Zero Data via Tool-Integrated Reasoning
当前核对版本：2511.16043v2，2026-09-21。
原文：https://arxiv.org/html/2511.16043v2
代码：https://github.com/aiming-lab/Agent0/tree/main/Agent0
核对：curriculum_reward.py、question_evaluate/evaluate.py与upload.py、executor_train/verl_tool/trainer/ppo/core_algos.py。

最有用的是课程模型与求解模型交替学习，课程随求解器能力变化，并保留难度筛选与多样性。ADPO对低自一致的伪标签减小优势权重，同时放宽探索上界。求解器仍以多数答案为伪标签；课程中的工具次数奖励也不等于工具真的帮助答对。因此不直接复制“调用越多奖励越大”或把自一致当视觉正确率。原文公式和当前默认脚本的缩放/截断细节也应分别说明，不能只冠名Agent0就声称精确复现。

4. Agent0-VL: Exploring Self-Evolving Agent for Tool-Integrated Vision-Language Reasoning
版本：2511.19900v2，2025-11-26。
原文：https://arxiv.org/html/2511.19900v2
代码：https://github.com/aiming-lab/Agent0/tree/main/Agent0-VL

可借鉴Solver—Verifier—Repair及工具证据约束。论文算法明确有SFT初始化，不能解释成从来没有监督前提。当前默认reward_manager/agent0.py还读取ground_truth字段并用数学答案评分形成outcome reward，配置alpha_out=1；本次没有核定该数据字段的实际来源，不能据此指控论文泄漏，但也不能把默认脚本当成已满足我们设定的无标签方案。工具执行成功只说明程序跑通，不说明某人符合语言查询。

5. Self-Evolving Visual Agent via Margin Reward（Marvo）
版本：2610.15084v1，2026-10-10。
原文：https://arxiv.org/html/2610.15084v1
代码：https://github.com/YWenxi/marvo
核对：examples/marvo/rewards/solver_scored.py与gold_answer.py。

这是本轮最贴近“怎样学会观察”的新增启发：奖励工具辅助与直接作答的成功率差，避免只追求困难或调用次数。代码确实分别调用两种求解模式再取差；其评分参照是出题者生成的MCQ答案，不是额外独立确认的图像真值。我们保留原RMOT查询，借鉴观察的边际价值，不能允许挑战者自行编答案证明自己正确，也不能直接搬来其均衡结论证明HOTA会提升。

6. SelectTTRL: Representation-Guided Data Selection for Efficient Test-Time Reinforcement Learning
版本：2610.16104v1，2026-10-12。
原文：https://arxiv.org/html/2610.16104v1
代码：https://github.com/heyiliyi/SelectTTRL-public

可借鉴先识别值得学习的问题，再支付昂贵采样成本。其具体COS方向从独立QA数据的答案对比中提取；不能偷偷用目标RMOT标签学“正确性方向”，也不照搬其百分位区间。这里的价值是观察价值预测与执行成本分开，而不是给现有不确定性换一个名字。

三、结合我们刚完成的实测，应该修正什么判断

1. 不能再把最早13个Dance探针对的低信息现象推广到全部设置。

新paid_pair_information审计固定每设置前min(10,N)个已完成视频，共48个设置内视频，分别检查LEARNED与FROZEN。C2/C5用已修正可比视角版本，其余用精确等价TRUST版本。只重建实际NativeVisual.record的元数据分组和轮转配对，逐前缀核对最终拟合行数，没有窥看未请求答案。

LEARNED保留探针的平均条件信息，C1..C6依次约：
0.106428、0.182008、0.170421、0.194689、0.180290、0.094593。
超过原0.005信息门槛的非空回合数依次为12/26、12/12、20/30、20/30、12/12、9/26。
所以不能说当前六设置普遍“教师全说No，反馈都没有信息”。奖励为零还可能来自更新前后都不如常量、未产生改进或探针稀疏；不能简单降低门槛制造正反馈。

2. 当前观察实际几乎只在拓展新轨迹，没有形成重复观察的证据设计。

这48个视频中，两策略每个已提问query-track组合都只有一个被请求时刻；重建出的监督配对全部跨轨迹。select_round中的fresh-or-available硬优先级与动作池结构足以解释这一现象：预算尚未看完新轨迹，所以不会回看。这不是A学出了最佳回看政策。

一个CLIP请求内部仍可能含多张历史帧，所以“请求时刻不重复”不等于“完全没有时序图像”。但它确实说明我们不能把当前付费轨迹写成已经学会“什么时候回头确认”。

LEARNED中同时满足同实际视角、同请求帧的跨候选配对比例，C1..C6约14.873%、0.911%、10.678%、8.624%、1.007%、13.357%。不同帧不自动意味着错误；它意味着要额外假设时刻/位置等状态差异不会混入相对身份学习。这项假设需要控制观察来检验。

3. 动态状态分量在现有教师探针上并非稳定有益。

state_probe审计读取同一48视频的第三轮checkpoint，位于最终全部问答拟合之前。断言当前视频全部保留query-track组没有用于这个checkpoint的训练；两种读法在同一CPU上运行，原full教师CE与已记GPU值最大差3.324e-7。

12个设置/策略汇总中9个为正、3个为负。这是已有模型的推理删除诊断，既不是重新训练identity-only的纯消融，也不是GT下的RMOT精度；不能据此宣称禁用状态必胜。C4/LEARNED等反例必须保留。它支持检查“动态变化有没有足够监督”，而不是无条件加时序平滑或无条件删掉状态。

4. 已有真实物理教师小试也没有支持全面增加回看。

不重复GPU小试，直接复查已完成24组同轨迹双时刻、72组同一时刻跨候选的INDEPENDENT_A/B通道。这些通道使用原正常二元教师输入，排除JOINT和SHARED两图上下文回答；共复用192个已实际计算的二元例。

同轨迹双时刻：24组，0组跨0.5阈值翻转，13组均No、11组均Yes；平均概率差0.039603，平均Bernoulli JS为0.007445，实际视角混配0。
同一时刻跨候选：72组，11组阈值不同；平均概率差0.171976，平均JS为0.083396；有4组CLIP回退导致实际视角不同，已单独记账，不能忽略。

两批问题、时刻和视角构成不同，样本也相关，所以两均值不是严格的因果比较；概率变化不等于真实成员变化，稳定回答不等于教师答对。当前证据更支持优先把候选比较做可比、把学习证据接好，而非给所有轨迹机械增加回看预算。是否针对某些动作/位置查询回看有用，仍需定向验证。

四、把启发收敛成三个相连的候选贡献

A. 学会选择有用的观察：由求解器推动观察者改变课程。

人类视觉启发是先扫视、对比疑似对象，有必要才再看。经典思想是实验设计和信息价值。RSI体现为：A选择真实候选/时刻/视角，冻结教师提供付费证据，S更新，新的保留教师探针检验S是否因此学会区分，再反馈更新A。A和S都是可学习的，Qwen保持冻结。

Marvo带来的改进问题是“观察的额外价值是什么”，而不只是“当前有多困惑”。可以用相同当前S、相同保留探针，比较获得该类观测后的教师风险下降与没有该观测/普通观察的变化。该差是教师代理价值，不是无标签条件下的真实HOTA奖励；对照额外拟合与探针也要计入预算和时间。不能用见过的训练答案自评，也不能只奖励调用多或后验更尖。

B. 从可比证据中学习候选区别。

人类视觉启发是在同一场景对比两个人。经典思想是条件似然和共同干扰的消去，落实到特征学习目标，而不是把现成算法挂在输出端。

若教师logit可以写成对象语义项加共享上下文偏差，那么同上下文两候选的logit差能消去该共享项；换时刻或换实际视角后，这个抵消不再自动成立。这个性质只在明确假设下成立，不能证明教师意见是真语义。下一轮应围绕同一时刻、实际视角可比的候选证据做学习对照，普通point/joint/logit蒸馏取得全部相同付费证据并充分优化。

RMOT仍可同时指多个目标，也允许都不匹配。局部exactly-one条件只用于区分监督，不是把整个任务改成单目标；both/neither与数量信息不能被偷偷丢弃。

C. 学会什么应该保留、什么需要新证据才能改变。

人类视觉启发是保持身份连续，同时允许动作和位置变化。经典思想是分层隐变量、可辨识性和部分共享：身份成分跨时刻共享，动态残差只有获得支持时才表达变化，而不是让一个自由逐帧头靠稀疏点标签随意漂移。

如果只在每个query-track的一个时刻获得监督，在一般的“身份项+该时刻状态项”分解中，可以有多种分解解释同一个观测；单凭拟合误差无法证明学到了正确身份/状态。实际网络的共享参数和正则会限制这种自由度，但不会凭空提供未观测的语义变化证据。需要用有控制的比较/重复观察，以及重新训练的identity-only、full-state对照检验，而不是只删已有网络的一部分就宣布贡献。

三个方向构成一个闭环：表示指出缺什么证据，观察策略补证据，相对学习把证据变成候选区分，新的表示再改变观察策略。它们目前仍是候选贡献，不能凭命名、参数变化或教师风险下降宣布论文三创新已经成立。

五、实验顺序与验收，不再无限增加小试

先完成正在运行的四项登记研究：native 726、TRUST 312、可比视角修正318、utility读出324。这些记录含多种输出、数量控制与精确父引用，不能相加当成独立视频样本。旧582已正式结束并保留负结果，不重启；当前新研究未全部封存前不读取其GT/HOTA。

接下来先检查现有表示在与其训练目标一致的读出下是否真正超过普通KD，再决定哪些新观察/表示机制值得完整实现。若仅换读出变好，只能说原接口掩盖了已有能力，不能算新的神经特征学习。若LEARNED与FROZEN不分胜负，不能宣称RSI成立。

下一项新机制研究固定一套统一方案、seed0、相同候选与问答预算，不按六个设置各挑模块。完整方案对普通充分KD、冻结观察者、条件学习删除、身份/状态学习删除，并做必要交互及逐query/frame双向CountMatched。原始问答路径交换回放用于区分选题和学习；所有正负结果保留。

最终入选方案另做同一次真实特征/教师/适配/输出的匹配质量与冷成本，不能拿缓存回放或共享卡耗时冒充部署成本。当前所有资料是DEV，没有独立新划分，不宣称盲测。

本轮没有因为文献启发再启动庞大队列，没有增加随机种子，没有动NAS历史结果。四卡0/1/2/3的实际任务继续；Goal保持ACTIVE。六个跨域实验设置都优于同信息普通蒸馏、三个贡献及其组合成立、真实成本核验，仍是必须完成的目标，而不是本报告已经达成的结论。
